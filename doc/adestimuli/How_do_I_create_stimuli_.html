How do I create stimuli?

如何创建激励？

Before creating stimuli, ensure that the prerequisites are met.

在创建激励之前，请确保满足 前提条件。

To create a new stimulus, follow the steps:

要创建新的激励，请按以下步骤操作：

  1. Enable authoring by selecting the On option in the Stimuli Authoring section.
    在 Stimuli Authoring 部分选择 On 选项以启用创作。
  2. Enter the stimulus name as an alphanumeric value.
    输入由字母数字组成的激励名称。
  3. Select the type of stimulus from a drop-down list next to the stimulus name field.
    从激励名称字段旁的下拉列表中选择激励类型。
  4. Select an option, I or V, to specify whether it is a current or voltage source.
    选择 I 或 V 选项，以指定是电流源还是电压源。

  5. Define the values of stimulus parameters.


    定义激励参数的值。

  6. Select the Show option in Preview Transient Waveforms.
    在  Preview Transient Waveforms 中选择Show 选项。
  7.  To preview the waveform, click Apply.
    要预览波形，请单击 Apply。

A short simulation runs. The new stimulus entry is added in the Stimuli Authoring section.

将运行一次短仿真。新的激励条目会添加到 Stimuli Authoring 部分。

You can also choose to create stimuli by either importing stimuli or creating a copy of stimuli to edit them.

你也可以选择通过 导入激励 或 创建激励副本 来创建激励并进行编辑。

All the stimuli definitions are saved at location — <Lib-name>/<Cell-name>/<View-name>/namedStimuli/stimuli.xml.
所有激励定义都保存在以下位置 — <Lib-name>/<Cell-name>/<View-name>/namedStimuli/stimuli.xml。
