How do I generate waveforms of the imported stimuli?

如何生成已导入激励的波形？

The stimuli imported from another design may not have waveforms or have waveforms not synchronized. You can generate the waveforms for such stimuli in two ways:

从其他设计导入的激励可能没有波形或波形未同步。你可以通过以下两种方式为这些激励生成波形：

  1. To generate a waveform for a stimulus, enable authoring by selecting the On option in the Stimuli Authoring section.
    要为激励生成波形，请在 Stimuli Authoring 部分选择 On 选项以启用 authoring。
  2.  Select Show in Preview Transient Waveforms. 
    选择 Show in Preview Transient Waveforms。

  3. Select one or more rows in the Variable Preview table and click Apply.


    在 Variable Preview 表中选择一行或多行，然后单击 Apply.

  4. To generate waveforms for all imported stimuli, run the maeStmGenerateWaveforms() command in the CIW.


    要为所有已导入激励生成波形，请在 CIW 中运行 maeStmGenerateWaveforms() 命令 。
