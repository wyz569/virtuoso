How do I preview a stimuli waveform?

如何预览激励波形？

You can preview a waveform for: 

你可以预览以下波形：

  1. Stimuli with waveforms already generated - These stimuli were either imported or created earlier.
    已生成波形的激励——这些激励要么是导入的，要么是之前创建的。
  2. For newly created stimuli.
    新创建的激励。

For scenario 1, you can preview the stimuli waveform in authoring disabled mode by performing either of the actions:

对于情形 1，你可以在禁用 authoring 模式下通过以下任一操作预览激励波形：

  • Select one or more stimuli and click . It opens Virtuoso Visualization and Analysis XL and shows the waveform previews of the stimuli.
    选择一个或多个激励并单击 。它会打开 Virtuoso Visualization and Analysis XL 并显示激励的波形预览。
  • Select a stimulus, right-click, and choose Plot transient waveform.
    选择一个激励，右键单击并选择 Plot transient waveform。

For scenario 2, first create a stimulus, and then follow the steps:

对于情形 2，先 创建激励，然后按以下步骤操作：

  1. Select the Show option in Preview Transient Waveforms. It opens the Variable Preview table. This table shows all the variable values and any sweeps. 
    在  Preview Transient Waveforms 中选择Show 选项。 它会打开 Variable Preview 表。 该表显示所有变量值以及任何扫描。 
  2. You can select one or more rows from the Variable Preview table to preview waveforms using these variables. 
    Learn more about selecting multiple sweeps in design variables
    你可以从 Variable Preview 表中选择一行或多行，以使用这些变量预览波形。 
    了解在设计变量中选择多个扫描的更多信息
  3. Click .
    It generates a Virtuoso Visualization & Analysis XL preview of the selected combination of variables.
    单击 。
    它会生成所选变量组合的 Virtuoso Visualization & Analysis XL 预览。

If the wave status for a stimulus appears a warning (), consider editing it and regenerating the waveform.
如果激励的波形状态显示警告（），请考虑编辑后重新生成波形。
