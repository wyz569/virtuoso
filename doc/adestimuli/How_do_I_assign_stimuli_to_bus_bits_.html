ADE Stimuli Assignment Quick Help
Product Version IC23.1, June 2023

How do I assign stimuli to bus bits?

如何将激励分配给总线位？

You can either assign the same stimulus to all the bus bits or different stimuli on different bus bits.
To assign the same stimulus to bus bits:

你可以将同一个激励分配给所有总线位，也可以在不同总线位上分配不同激励。
要将同一激励分配给总线位：

  1. Select a stimulus.
    选择一个激励。
  2. Select a bus in the Pin Assignment section.
    在 Pin Assignments 部分选择一条总线。
  3. Click  in the toolbar of the Pin Assignments section.
    在 Pin Assignments 部分的工具栏中单击 。

To assign different stimuli on the bus bits, perform the following steps for each stimulus:

要在总线位上分配不同的激励，请针对每个激励执行以下步骤：

  1. Select a stimulus.
    选择一个激励。
  2. Select the required bus bit.
    选择所需的总线位。
  3. Click  in the toolbar of the Pin Assignments section.
    在 Pin Assignments 部分的工具栏中单击 。
  4. Repeat these steps for each bus bit.


    对每个总线位重复以上步骤。

You can choose to leave a bus bit unassigned only if it is disabled. To disable an unassigned bus bit, right-click the bus bit and select Disable Selected Bus Bits.
只有在禁用总线位时，才可以选择不分配激励。要禁用未分配的总线位，请右键单击该总线位并选择 Disable Selected Bus Bits。
