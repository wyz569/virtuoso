ADE Stimuli Assignment Quick Help
Product Version IC23.1, June 2023

How do I assign stimuli to design components?

如何将激励分配给设计组件？

To assign stimuli, ensure that the authoring mode is disabled by selecting the Off option in the Stimuli Authoring section.

要分配激励，请在 Stimuli Authoring 部分选择 Off 选项，以确保创作模式已禁用。

All the design components, such as pins, buses, and global nets, are automatically fetched and are visible as a list in the Pin Assignments section. To assign a stimulus to one or more of these components, follow the steps:

所有设计组件（如引脚、总线和全局网络）会自动获取，并在 Pin Assignments 部分以列表形式显示。要将激励分配给一个或多个组件，请按以下步骤操作：

  1. Select the stimulus.


    选择激励。

  2. Select one or more input pins in the Pin Assignments section.

    You can choose to select the Show Unassigned Pins check box in the toolbar of the Pin Assignments section to display the pins that do not have any stimuli assigned to them. 
    你可以在 Pin Assignments 部分的工具栏中选中 Show Unassigned Pins 复选框，以显示尚未分配任何激励的引脚。


    在 Pin Assignments 部分选择一个或多个输入引脚。

  3. Click  in the toolbar of Pin Assignments section.

    Alternatively, right-click one or more pins in the Pin Assignments section and choose Assign Stimuli to Selected Pins.


    在 Pin Assignments 部分的工具栏中单击 。

    或者，在 Pin Assignments 部分中右键单击一个或多个引脚，选择 Assign Stimuli to Selected Pins。

  4. Validate the status in the Stimuli column for the selected input pin to be updated to Assigned.
    确认所选输入引脚在 Stimuli 列中的状态已更新为 Assigned。

You should run the simulation after the pin assignments are complete.
在引脚分配完成后，应运行仿真。
