How do I create the copy of a stimulus?

如何创建激励的副本？

You can create a new stimulus by copying an existing one by performing the following steps:

你可以通过复制现有激励来创建新的激励，步骤如下：

  1. Ensure that the authoring mode is enabled by selecting the On option in the Stimuli Authoring section.
    在 Stimuli Authoring 部分选择 On 选项以确保创作模式已启用。
  2. Select the source stimulus in the Stimuli Authoring section.
    在 Stimuli Authoring 部分选择源激励。
  3. Rename the stimulus.
    重命名该激励。
  4. If required, modify the parameter values.
    如有需要，修改参数值。
  5. To preview its waveform, select Show in Preview Transient Waveforms.
    要预览其波形，请选择 Show in Preview Transient Waveforms。
  6. It opens the Variable Preview table that shows all the parameters and their respective values set in the stimulus.
    这会打开 Variable Preview 表，其中显示激励中设置的所有参数及其对应值。
  7. Select one or more rows in the Variable Preview table and click Apply.
    在 Variable Preview 表中选择一行或多行，然后单击 Apply.

A new stimulus is created and its name is added to the list of available stimuli.

新的激励会被创建，其名称会添加到可用激励列表中。
