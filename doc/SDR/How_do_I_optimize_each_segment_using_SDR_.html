Product Version IC23.1, June 2023

How do I optimize each segment using SDR?

如何使用 SDR 优化每一段线段？

Use the tapering feature to show how each segment can be optimized by SDR.

使用渐缩（tapering）功能来展示 SDR 如何对每一段线段进行优化。

Note: Tapering is available only in Enforce checker mode for all current estimation modes.

注意: 渐缩仅在所有电流估算模式的 Enforce 检查器模式中可用。

To adjust the width and taper each segment independently: 

要独立调整每一段的线宽并进行渐缩： 

  1. Select a net from the Navigator Assistant or the EAD Browser.
  2. 从 Navigator Assistant 或 EAD Browser 中选择一个网络。
  3. Choose Create – Wiring – Wire. 
    Note: The tapering is available only for the Create Wire command.
  4. 选择 Create – Wiring – Wire。 
    注意: 渐缩仅对 Create Wire 命令可用。
  5. Select an instance from where you want to start creating the wire. By default, the taper mode is noTaper. This means that the wire width remains constant even after connecting the pins.
  6. 选择要开始创建导线的实例。 默认情况下，渐缩模式为 noTaper。这意味着即使连接了引脚，导线宽度也保持不变。
  7. To enable tapering, press }.
    When tapering is enabled, the width of each segment is independently adjusted to match the estimated current value. The following figure shows how a wire width is adjusted when tapering is enabled.
  8. 要启用渐缩，按 }。
    启用渐缩后，每段的宽度会独立调整以匹配估算的电流值。下图展示了启用渐缩时导线宽度如何被调整。


When there are no additional connected shapes for the edited wire and you continue to move the mouse pointer in the same direction, then after crossing the last target, the tapering of the wire moves in the opposite direction.


当被编辑的导线没有额外的已连接形状，并且你继续沿同一方向移动鼠标指针时，越过最后一个目标后，导线的渐缩会朝相反方向移动。
