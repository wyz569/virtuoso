Product Version IC23.1, June 2023

How do I perform resistance-driven interactive routing?

如何执行电阻驱动的交互式布线？

When you start the Create Wire command, the wires and vias interactively connect the pins and automatically estimate the final resistance between the two pins. Based on the estimated resistance and the maxResistance constraint, the wire width and via num cuts of the wire and via being edited are automatically sized so that the final wire resistance is below the value of the maxResistance constraint.
The SDR Maximum Resistance Check mode is disabled for the Create Stranded Wire command. Even when the mode is set to maxResistance through the weSdrElectricalMode environment variable, the Create Stranded Wire command behaves as if the EM mode is enabled.
To run maximum resistance check:

当你启动 Create Wire 命令时，导线与过孔会交互式地连接引脚，并自动估算两引脚之间的最终电阻。基于估算电阻与 maxResistance 约束，正在编辑的导线与过孔会自动调整导线线宽以及过孔的切割数（via num cuts），使最终导线电阻低于 maxResistance 约束值。
SDR 最大电阻检查模式对 Create Stranded Wire 命令无效。即使通过 weSdrElectricalMode 环境变量将模式设置为 maxResistance，Create Stranded Wire 命令的行为也会与启用 EM 模式时一致。
要运行最大电阻检查：

  1. Select a pin or an instance that you want to route.
  2. Click the drop-down arrow next to Interactive SDR Mode on SDR Toolbar.
  3. Select the Interactive SDR Max Resistance Check option from the drop-down list.
    Note: When the Interactive SDR Max Resistance option is selected, the icons on the SDR toolbar are updated with the icons for maximum resistance.
  4. To control the scaling factor applied to the target resistance when sizing the wires or displaying the resistance information, specify a value in the Max Resistance Target Percentage text box on SDR Toolbar. For example, if you specify the maximum resistance percentage as 50%, it means that the wire is oversized to reach a resistance of 0.5*maxResistance.
  5. Choose Create – Wiring – Wire.
  6. Start creating a wire from the selected pin or the instance.
  7. Click the drop-down arrow next to the Checker Mode icon on SDR Toolbar.
  8. From the drop-down menu, select a checker mode. You can select one of the following checker modes: Checker Mode: Enforce, Checker Mode: Notify, or Checker Mode: Off.
  9. To toggle between multiple maxResistance constraints, click the Cycle Max Resistant Constraints button on SDR Toolbar.
  10. To complete interactive routing, press Enter.
  1. 选择要布线的引脚或实例。
  2. 在 SDR 工具栏上点击 Interactive SDR Mode 旁的下拉箭头。
  3. 从下拉列表中选择 Interactive SDR Max Resistance Check 选项。
    注：当选择 Interactive SDR Max Resistance 选项后，SDR 工具栏图标会更新为最大电阻相关图标。
  4. 为控制在导线定尺寸或显示电阻信息时应用于目标电阻的缩放因子，在 SDR 工具栏的 Max Resistance Target Percentage 文本框中指定一个值。例如，若将最大电阻百分比设为 50%，表示导线会被加宽，使其电阻达到 0.5*maxResistance。
  5. 选择 Create – Wiring – Wire。
  6. 从所选引脚或实例开始创建导线。
  7. 点击 SDR 工具栏上 Checker Mode 图标旁的下拉箭头。
  8. 从下拉菜单中选择检查器模式。可选模式包括：Checker Mode: Enforce、Checker Mode: Notify 或 Checker Mode: Off。
  9. 要在多个 maxResistance 约束之间切换，点击 SDR 工具栏上的 Cycle Max Resistant Constraints 按钮。
  10. 要完成交互式布线，按 Enter。
