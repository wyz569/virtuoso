How do I perform a current density check in interactive SDR?

如何在交互式 SDR 中执行电流密度检查？

Based on the simulation results, Create Wire estimates the current in the edited wire and vias according to the EAD settings, such as dataset, temperature, and current scaling. The current density check lets you create a design with the appropriate width of the wire based on the estimated EM value.
To run the current density check:

基于仿真结果，Create Wire 会根据 EAD 设置（例如数据集、温度以及电流缩放）估算已编辑导线与过孔中的电流。电流密度检查可根据估算的 EM（电迁移）值，帮助你以合适的线宽创建设计。
要运行电流密度检查：

  1. Select a net in the Navigator assistant or the EAD browser.
  2. Select an active layer in the Palette.
  3. Click the drop-down arrow next to the Interactive SDR Mode button on SDR Toolbar.
  4. Select the Interactive SDR Current Density Check option from the Interactive SDR Mode drop-down list.
  5. To control the wire size and the number of strands compared to the estimated width required to avoid EM violations, specify a value in the Width Multiplier text box on the SDR toolbar. For example, if you specify the width multiplier as 2.0, it means that the stranded width is multiplied by 2 compared to the estimated width to reach 100% of EM. Either the width of each strand is increased or the number of strands are increased.
  6. Start to create a wire or a stranded wire from the selected pin or instance.
    1. Choose Create – Wiring – Wire or press P.
    2. Choose Create – Wiring – Create Stranded Wire or press Ctrl + Shift + S.
      When you start the Create Wire or the Create Stranded Wire command, the wires and vias interactively connect the pins and the software automatically estimates the current between the two pins.
      Based on the estimated current, the wire width and number of via cuts are automatically resized so that the estimated current of the wire is below the value of the final current of the wire.
  7. Select a checker mode from the Checker Mode drop-down list. You can select one of the following checker modes: Checker Mode: Enforce, Checker Mode: Notify, or Checker Mode: Off. 
  8. To control the current estimation of wire, select a current estimation mode. You can select one of the following current estimation modes: Auto, Sum Connected Pins Current, Maintain Constant Current, and Nearest Island Current.
  9. To complete interactive routing, press Enter.
  10. Run EM checks as follows.
    1. Click Extract Parasitics on EAD Toolbar.
    2. Click Run EM Checks on EAD Toolbar.
  11. To display the EM violations, click Highlight EM violations on the EM tab of the Details pane of the EAD Browser.
    This completes simulation-driven routing and EM checking for the design.

Related Topics

  1. 在 Navigator assistant 或 EAD browser 中选择一个网络。
  2. 在 Palette 中选择一个活动层。
  3. 在 SDR 工具栏上点击 Interactive SDR Mode 按钮旁的下拉箭头。
  4. 在 Interactive SDR Mode 下拉列表中选择 Interactive SDR Current Density Check 选项。
  5. 为控制导线尺寸以及股线数量（相对于避免 EM 违规所需的估算线宽），在 SDR 工具栏的 Width Multiplier 文本框中指定一个值。例如，将宽度倍数设为 2.0 表示股线总宽度在估算线宽基础上乘以 2，以达到 100% EM 的目标。你可以通过增大每股线宽或增加股数来实现。
  6. 从所选引脚或实例开始创建导线或股线导线。
    1. 选择 Create – Wiring – Wire 或按 P。
    2. 选择 Create – Wiring – Create Stranded Wire 或按 Ctrl + Shift + S。
      当你启动 Create Wire 或 Create Stranded Wire 命令时，导线与过孔会交互式地连接引脚，软件会自动估算两引脚之间的电流。
      基于估算电流，导线线宽与过孔切割数（via cuts）会自动调整，使导线的估算电流低于导线最终电流的目标值。
  7. 从 Checker Mode 下拉列表中选择检查器模式。可选模式包括：Checker Mode: Enforce、Checker Mode: Notify 或 Checker Mode: Off。
  8. 为控制导线的电流估算，选择一种电流估算模式。可选模式包括：Auto、Sum Connected Pins Current、Maintain Constant Current 和 Nearest Island Current。
  9. 要完成交互式布线，按 Enter。
  10. 按以下步骤运行 EM 检查。
    1. 在 EAD 工具栏点击 Extract Parasitics。
    2. 在 EAD 工具栏点击 Run EM Checks。
  11. 要显示 EM 违规，在 EAD Browser 的 Details 窗格的 EM 选项卡上点击 Highlight EM violations。
    至此完成该设计的仿真驱动布线与 EM 检查。
