Creating an Overlap Boundary
创建重叠边界

The overlap boundary is a detailed boundary used by placement tools to test whether cells overlap. Unlike the PR boundary, which is always rectangular, the overlap boundary can be a rectilinear polygon. This helps the placement tools achieve better placement density for certain types of standard cells and rectilinear blocks.
重叠边界（overlap boundary）是一种更精细的边界，放置工具会用它来检测单元是否发生重叠。与始终为矩形的 PR 边界不同，重叠边界可以是正交多边形（rectilinear polygon）。这有助于放置工具在某些类型的标准单元与正交模块上实现更高的放置密度。

To create an overlap boundary:
要创建重叠边界：

  1. Choose Flow – Abstract, and click the Overlap tab in the Running step Abstract for the selected cell(s) form.
    选择 Flow – Abstract，并在所选 cell(s) 的 Running step Abstract 窗体中单击 Overlap 选项卡。
    The options on this tab control whether Abstract Generator is to update the overlap boundary geometry.
    该选项卡上的设置用于控制 Abstract Generator 是否更新重叠边界几何。
  2. Use the Create overlap boundary option to specify whether Abstract Generator should create an overlap boundary.
    使用 Create overlap boundary 选项指定 Abstract Generator 是否应创建重叠边界。
  3. In the Using geometry on layers field, specify the layers to be used in the overlap boundary calculation. The boundary is drawn so that it encloses all the geometry found on these layers.
    在 Using geometry on layers 字段中，指定用于计算重叠边界的层。边界会被绘制为包围这些层上找到的全部几何。
  4. In Size factor to apply, specify (in microns) the value by which an overlap layer is to be increased.
    在 Size factor to apply 中，以微米为单位指定重叠层要扩大的数值。
  5. In Smooth factor to apply, specify the value that controls the shape of the overlap layer that is produced.
    在 Smooth factor to apply 中，指定用于控制所生成重叠层形状的数值。
  6. Click Run.
    单击 Run。

An overlap boundary is created as per the specifications
将按所设定的规格创建重叠边界。

Creating an Overlap Layer in OpenAccess
在 OpenAccess 中创建重叠层

As there is no concept of an overlap layer in OpenAccess, Abstract Generator creates the overlap shape on the PR boundary layer. If you export LEF for the cellview, the overlap shape is correctly written to the OVERLAP section.
由于 OpenAccess 中没有“重叠层（overlap layer）”的概念，Abstract Generator 会在 PR boundary 层上创建重叠形状。如果你为该 cellview 导出 LEF，重叠形状会被正确写入 OVERLAP 区段。

If you create or update the PR boundary by using the options on the Boundary Tab and then create an overlap layer by using the options on the Overlap tab, the PR boundary is destroyed and replaced with the overlap shape.
如果你先通过 Boundary 选项卡的设置创建或更新 PR boundary，然后再通过 Overlap 选项卡的设置创建重叠层，PR boundary 会被删除并替换为重叠形状。

Troubleshoot OAToolbox Issues
排查 OAToolbox 问题

You can face the following issues while using open access toolbox in Abstract Generator.
在 Abstract Generator 中使用 OpenAccess toolbox 时，可能会遇到以下问题。

ABS-11500

Cell name: Row name in view viewName has a missing property propertyName and will not be converted.
Cell name：视图 viewName 中的行 name 缺少属性 propertyName，因此不会被转换。

ABS-11501

Cell name: Row name in view viewName references a site def siteDefName which has not been defined in the technology database.
Cell name：视图 viewName 中的行 name 引用了站点定义 siteDefName，但该站点定义尚未在技术数据库中定义。

ABS-11502

Couldn’t open master libName, cellName, viewName, referenced in cellview libName, cellName, viewName.
无法打开 cellview libName、cellName、viewName 中引用的 master：libName、cellName、viewName。
