Pins Step in Standalone Abstract Generation
独立版抽象生成中的 Pins 步骤

The Pins step describes the first step in the abstract generation process. Usually, no pins are explicitly defined in the layout view, so they have to be generated before you can continue the abstract generation process. Abstract Generator derives pins from the text labels in the layout view and places the locations at the text origins.

Pins 步骤描述抽象生成过程的第一步。通常，版图视图中不会显式定义引脚，因此在继续抽象生成过程之前必须先生成引脚。抽象生成器从版图视图中的文本标签派生引脚，并将位置放在文本原点处。

  • If there is a logical view present, Abstract Generator only creates pins that match logical view terminals.
    如果存在逻辑视图，抽象生成器只创建与逻辑视图端口匹配的引脚。
  • Abstract Generator copies the placement status of the pins in the layout view to the abstract view. The supported placement states are locked, placed, fixed, none, and unplaced.
    抽象生成器将版图视图中的引脚放置状态复制到抽象视图。支持的放置状态为 locked、placed、fixed、none 和 unplaced。
  • Abstract Generator automatically detects shapes placed in width spacing pattern (WSP) regions and ignores these shapes while creating pins under labels and PR boundaries.
    抽象生成器会自动检测放置在宽间距模式（WSP）区域中的图形，并在在标签下及 PR 边界下创建引脚时忽略这些图形。

Abstract Generator provides a number of options that support a variety of layout and text mapping conventions. To check options for mapping and for controlling the generation of pins, see Specifying Pin Mappings for Abstract Generation.

抽象生成器提供多种选项，以支持不同的版图与文本映射约定。要查看用于映射以及控制引脚生成的选项，请参见 指定用于抽象生成的引脚映射。

Abstract Generator performs the following functions during the Pins step:

抽象生成器在 Pins 步骤期间执行以下功能：

  • Maps text labels to terminal names and creates terminals
    将文本标签映射到端口名称并创建端口
  • Creates physical pin shapes corresponding to the geometry overlapping the text labels
    创建与文本标签重叠几何形状对应的物理引脚图形
  • Creates the place-and-route boundary
    创建布线边界（place-and-route boundary）

You can use the Running step Pins form to view and modify the bin options relevant to the Pins step.

您可以使用 Running step Pins 表单查看并修改与 Pins 步骤相关的 bin 选项。

To run the Pins step:

运行 Pins 步骤：

  1. Select one or more cells in the main window and click the Pins button. Alternatively, select Flow – Pins command.
    This opens the Running step Pins form. There are four tabs on the Running step Pins form: Map, Text, Boundary, and Blocks. You can use the radio buttons on the left to navigate to the tab pages for the different steps and bins you are using in the Running step Pins form.
    在主窗口中选择一个或多个单元并单击 Pins 按钮。或者，选择 Flow – Pins 命令。
    这会打开 Running step Pins 表单。该表单包含四个选项卡：Map、Text、Boundary 和 Blocks。您可以使用左侧的单选按钮，在 Running step Pins 表单中导航到您正在使用的不同步骤和 bin 的选项卡页面。
  2. When you are satisfied with the options settings, click Run to run the step.
    当您对选项设置满意后，单击 Run 运行该步骤。

The Percent Complete message box reports the progress of the step. When the Pins step is complete, Abstract Generator places a symbol against the cell in the Cell pane to indicate the status of the Pins view that was created.

Percent Complete 消息框会报告该步骤的进度。当 Pins 步骤完成后，抽象生成器会在 Cell 窗格中对应的单元旁放置一个符号，用于指示所创建 Pins 视图的状态。
