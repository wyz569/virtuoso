Specifying Power and Ground Rail Characteristics
指定电源与地轨特性

To specify the characteristics of the power and ground rails for the current bin:
要为当前 bin 指定电源轨与地轨的特性：

  1. Choose Flow – Abstract. The Adjust tab is the first tab in the Running step Abstract form.
    选择 Flow – Abstract。Adjust 选项卡是 Running step Abstract 窗体中的第一个选项卡。
  2. In the Signal Nets section, you can control how pin shapes are adjusted during connectivity extraction to create the final required pin shapes for signal nets.
    在 Signal Nets 区域中，你可以控制在连通性抽取过程中如何调整引脚形状，以生成信号网所需的最终引脚形状。
  3. In the Power Nets section, you can control how pin shapes are adjusted during connectivity extraction to create the final required pin shapes for power nets.
    在 Power Nets 区域中，你可以控制在连通性抽取过程中如何调整引脚形状，以生成电源网所需的最终引脚形状。
  4. Use Power rail widths, offsets and shape to specify the characteristics of the power and ground rails for the current bin.
    使用 Power rail widths、offsets and shape 来为当前 bin 指定电源轨与地轨的特性。
  5. Open the Power rail widths, offsets and shape table.
    打开 Power rail widths, offsets and shape 表。
    The table contains a separate row for each power rail.
    该表中每一条电源轨对应一行。
    The Power rail widths, offsets and shape option will be unavailable if the Create ring pins option is selected. The Create ring pins option is available only if you are processing a block.
    如果选择了 Create ring pins 选项，则 Power rail widths, offsets and shape 选项不可用。Create ring pins 仅在处理 block 时可用。
    If you try to process a block in the Core bin, the Power rail widths, offsets and shape option will lead to a long run time. To avoid this, process blocks in the Block bin.
  6. Use Net to specify the net name in this column.
    使用 Net 在该列中指定网络名。
  7. Select Shape to select from feedthru, abutment, calculate and none.
    在 Shape 中从 feedthru、abutment、calculate、none 中选择。
  8. Use Width to specify the rail width (in μ) in this column.
    使用 Width 在该列中指定轨宽（μ）。
  9. Use Offset to specify the rail position (in μ) in this column.
    使用 Offset 在该列中指定轨位置（μ）。
  10. You can insert or delete rows from the table by selecting the appropriate button, Add or Delete.
    你可以通过选择相应的按钮 Add 或 Delete 来插入或删除表中的行。
  11. Check the box to the left of a row to mark it for deletion. If the table is left empty, Abstract Generator will try to determine the rail data for the Core bin, including calculating the rail and its shape. For Block and IO bins, no calculations are performed if the table is left empty. This is the default situation.
    勾选某行左侧的复选框可将其标记为删除。如果表为空，Abstract Generator 会尝试为 Core bin 确定轨数据（包括计算轨及其形状）。对于 Block 与 IO bin，如果表为空则不会执行计算。这是默认情况。

The table below describes the impact and resultant of selecting one of these values in the Shape column.
下表描述了在 Shape 列中选择这些取值之一所产生的影响与结果。

Net Shape
网络 Shape 		Implication
含义 		Default Setting
默认设置

feedthru

The Width and Offset values do not need to be set because no calculation is performed.
由于不会执行计算，因此无需设置 Width 与 Offset 数值。

The terminal associated with that net will be given this shape property
与该网络关联的端子将被赋予此 shape 属性。

Available for IO, Corner, and Block bins.
适用于 IO、Corner 与 Block bin。

abutment

calculate

The Width and Offset values must be entered for ALL nets because all power rail nets must be calculated.
由于需要对所有电源轨网络进行计算，因此必须为所有网络输入 Width 与 Offset 数值。

Available only for cells in the Core bin.
仅适用于 Core bin 中的 cell。

none

No calculation will be performed.
不会执行任何计算。

Available for IO, Corner, and Block bins.
适用于 IO、Corner 与 Block bin。

You cannot set the same power rail net more than once with different Shape values associated with it.
同一个电源轨网络不能以不同的 Shape 取值重复设置多次。

If the Power rail widths, offsets and shape option is set to feedthru, abutment or none, Abstract Generator will only use the specified values to set terminal properties. That is, if only one power rail net is entered into the table, that will be the only rail used to set terminal properties.
如果 Power rail widths, offsets and shape 选项设置为 feedthru、abutment 或 none，Abstract Generator 只会使用表中指定的数值来设置端子属性。也就是说，如果表中仅输入了一个电源轨网络，那么它将是唯一用于设置端子属性的轨。

If Abstract Generator establishes that a rail can be represented by either a feedthru or an abutment rail, it will always choose the abutment shape, as shown below.
如果 Abstract Generator 判断某条轨既可以表示为 feedthru 也可以表示为 abutment，则它始终会选择 abutment 形状，如下所示。
