Specifying the CDS.log File Name

指定 CDS.log 文件名

To specify a unique log file name using the CDS_LOG_VERSION environment variable:

使用环境变量 CDS_LOG_VERSION 指定唯一的日志文件名：

  • Set the variable before starting the Cadence software or include the setenv command in your .cshrc file:
    在启动 Cadence 软件之前设置该变量，或在你的 .cshrc 文件中加入 setenv 命令：
    setenv CDS_LOG_VERSION {sequential | pid}

Here:

其中：

  • sequential adds a sequential number to the name of the log file, such as CDS.log.1 or CDS.log.2
    sequential 会在日志文件名后添加顺序编号，例如 CDS.log.1 或 CDS.log.2
  • pid adds the number of the UNIX process to the name of the log file, such as CDS.log.1719 or CDS.log.2250
    pid 会在日志文件名后添加 UNIX 进程号，例如 CDS.log.1719 或 CDS.log.2250
