Exporting a Report in Abstract Generator

在 Abstract Generator 中导出报表

The report function outputs a summary of the cells in your library. It contains statistical information about the whole library, such as the number of cells by type and the number of cells with errors or warnings, and more detailed information about each of the individual cells.

报表（report）功能会输出库中 cell 的摘要信息。它包含整个库的统计信息，例如按类型划分的 cell 数量、包含错误或警告的 cell 数量，以及每个单独 cell 的更详细信息。

The report file contains:

报表文件包含：

  • General information about the tool version
  • Date and time the report was generated
  • Details of the number of errors and warnings generated during the current session
  • Total number of cells by type
  • Number of cells with errors or warnings
  • Number of cells with valid logical views but no layout views
  • 工具版本的基本信息
  • 生成报表的日期与时间
  • 当前会话期间产生的错误与警告数量明细
  • 按类型统计的 cell 总数
  • 包含错误或警告的 cell 数量
  • 具备有效 logical 视图但没有 layout 视图的 cell 数量

To export a report:

导出报表的步骤如下：

  1. Choose File – Export – Report to start this command.
    This displays the Export Report form.
  2. In Report Filename, specify a path and name for the file to be exported, or use the Browse function to help you specify the location.
  3. Click OK to export the report to the specified file location.
  1. 选择 File – Export – Report 启动该命令。
    系统会显示 Export Report 表单。
  2. 在 Report Filename 中指定要导出的文件路径与文件名，或使用 Browse 功能辅助选择位置。
  3. 点击 OK 将报表导出到指定的文件位置。
