Import Logical Form

导入逻辑表单

Use the Import Logical form to create cellviews from existing logical information, typically represented in Liberty or Verilog® formats.

使用 Import Logical 表单可从现有逻辑信息创建 cellview，逻辑信息通常以 Liberty 或 Verilog® 格式表示。

Field
字段 		Description
说明

Logical Filenames
逻辑文件名

Specifies the name of one or more files you want to import, or use the Browse button to help locate the file and add it to the selection.

指定要导入的一个或多个文件名，或使用 Browse 按钮查找文件并将其添加到选择列表中。

Filetype
文件类型

Lets you filter the required file format by using a search list. Abstract Generator creates cells with logical views in the current library directory. If the cell already exists, Abstract Generator does not create a new cell but adds logical view information to the other views present for the cell.

通过搜索列表筛选所需的文件格式。Abstract Generator 会在当前库目录中创建带有 logical view 的单元；如果该单元已存在，则不会新建单元，而是将 logical view 信息添加到该单元已有的其他视图中。

If you import logical information after you have run the Pins step, Abstract Generator confirms that the layout and logical views match before extracting terminal properties from the logical view. Cells that have only a logical view go to the Ignore bin by default.

如果在完成 Pins 步骤后再导入逻辑信息，Abstract Generator 会在从 logical view 提取端口属性之前，先确认 layout 与 logical view 是否匹配。仅包含 logical view 的单元默认会进入 Ignore bin。
