Troubleshoot Abstract Messages
排查 Abstract 消息

ABS-14003

Message:
消息：

Cell name: the power ring for net name only contains value shapes that are within value microns of the boundary. There must be at least four shapes within this distance. This is determined using the shape closest to the cell boundary. See Customizing Pin Shapes in Standalone Abstract Generator.
单元 name：网络 name 的电源环仅包含距离边界 value 微米以内的 value 个形状。该距离范围内必须至少有四个形状。该距离使用最靠近单元边界的形状来判定。参见 在独立 Abstract Generator 中自定义引脚形状。

ABS-14006

Message:
消息：

There are no power and ground rails common to all cells in the current bin. Use the Power Rail Widths and Offsets option to specify the characteristics of the power and ground rails for the bin. You might also need to redistribute cells into separate bins to complete this step.
当前 bin 中没有所有单元共用的电源与地电源轨。使用 Power Rail Widths and Offsets 选项为该 bin 指定电源与地电源轨的特性。你可能还需要将单元重新分配到不同的 bin 中以完成此步骤。

ABS-14007

Message:
消息：

Cell name: contains non-orthogonal geometry which cannot be modeled. There are value cells with non-orthogonal geometry.
单元 name：包含无法建模的非正交几何。共有 value 个单元具有非正交几何。

Description:
说明：

The design contains one or more cells containing diagonal geometry which Abstract Generator cannot model.
该设计包含一个或多个带有对角几何的单元，Abstract Generator 无法对其建模。

Abstract Generator usually adopts the stair-step coverage method in order to model 45-degree geometry, but this method failed on the named cells. It could be that the intersection of the 45-degree shape and the stair-step is too small to be processed by Abstract Generator.
Abstract Generator 通常使用阶梯（stair-step）覆盖方法来建模 45 度几何，但该方法在所述单元上失败。可能原因是 45 度形状与阶梯近似区域的交叠过小，导致 Abstract Generator 无法处理。

Troubleshooting:
故障排查：

Increase the size of your stair step and run Abstract Generator again. If the problem persists, consider editing your layout data.
增大阶梯近似的步长后重新运行 Abstract Generator。如果问题仍然存在，请考虑修改版图数据。

  • For information about the stair-step model, see Pin and Blockage Fracturing.
    关于阶梯（stair-step）模型的信息，参见 引脚与阻挡分割。
  • For information about designing library data for use in Cadence flows, see Appendix D, “Library Design Guidelines.”
    关于为 Cadence 流程设计库数据的信息，参见 附录 D《库设计指南》。

ABS-14008

Message:
消息：

Cell name: terminal name shape name is different from the calculated value value. You can reset shape properties using the Terminal Properties form.
单元 name：端子 name 的形状 name 与计算得到的 value value 不一致。你可以使用 Terminal Properties 表单重置形状属性。

Description:
说明：

The shape value calculated for the named terminal is different from the value already stored in the cellview. Abstract Generator is unable to reset the property value.
为所述端子计算得到的 shape value 与 cellview 中已存储的值不同。Abstract Generator 无法重置该属性值。

ABS-14013

Message:
消息：

Cell name: The blockage type selected for the layer name in the Layer Assignment for the Blockages table is Shrink. However, no value is specified for either Shrink Track or Shrink Dist. If you do not specify a value in either of these columns corresponding to the layer, the abstract generator will use the default value of 2 tracks for creating the blockage. This default value is small and will increase the run time of the Abstract step significantly. If you want to avoid this, you must specify either the Shrink Track or Shrink Dist value or both.
单元 name：在 Layer Assignment for the Blockages 表中，为层 name 选择的阻挡类型为 Shrink。但 Shrink Track 与 Shrink Dist 均未指定值。如果你未在与该层对应的任一列中指定值，abstract generator 将使用默认值 2 tracks 来创建阻挡。该默认值较小，会显著增加 Abstract 步骤的运行时间。若要避免此问题，必须指定 Shrink Track 或 Shrink Dist 的值，或两者都指定。

Description:
说明：

If you choose the type of blockage you want create on a layer as Shrink in the Blockage column of the Layer Assignment for Blockages table on the Blockage tab (Abstract step), you need to specify a distance value (in microns) in the Shrink Dist field. Alternatively, you can specifiy a value in terms of the number of tracks between the blockages in the Shrink Track field. Abstract Generator combines blockages that are within the specified distance from each other or are separated by the specified number of tracks by filling the space between them with more blockage.
如果你在（Abstract 步骤的）Blockage 选项卡上 Layer Assignment for Blockages 表格的 Blockage 列中，将某层要创建的阻挡类型选择为 Shrink，则需要在 Shrink Dist 字段中指定距离值（微米）。或者，你也可以在 Shrink Track 字段中以阻挡之间的轨道数来指定值。Abstract Generator 会通过用更多阻挡填充其间空间，将彼此间距小于等于指定距离、或相隔轨道数小于等于指定值的阻挡合并。

If you specify both Shrink Track and Shrink Dist, the values are added and blockages separated by a distance less than or equal to the total distance are merged. If you do not supply a distance, Abstract Generator uses a default value of 2 tracks and displays this warning message.
如果同时指定 Shrink Track 与 Shrink Dist，两个值将相加；间距小于等于总距离的阻挡会被合并。如果未提供距离，Abstract Generator 将使用默认值 2 tracks，并显示此警告消息。

overlap 层上存在超出 place-and-route 边界的几何。

Message:
消息：

Cell name: no overlap layer shapes have been generated. Check that the layers have been specified in the Using geometry on layers field. See Retain Layout Information in the Abstract View.
单元 name：未生成任何 overlap 层形状。请检查是否已在 Using geometry on layers 字段中指定相关层。参见 在 Abstract 视图中保留版图信息。

ABS-14017

Message:
消息：

Cell name: has more than one overlap shape generated. Check the layers specified in the Using geometry on layers field and the abstract view.
单元 name：生成了多个 overlap 形状。请检查 Using geometry on layers 字段中指定的层以及 abstract 视图。

Description:
说明：

The geometry you supplied in the Using geometry on layers field in the Overlap tab has led to the tool creating more than one shape for the overlap layer.
在 Overlap 选项卡的 Using geometry on layers 字段中提供的几何，导致工具为 overlap 层创建了多个形状。

This error might also appear if the shapes to be considered for creating the overlap boundary exist on the boundary purpose, whereas only the layer(s) is specified in the Using geometry on layers field.
如果用于创建 overlap boundary 的形状存在于 boundary purpose 上，但在 Using geometry on layers 字段中仅指定了 layer（未包含 purpose），也可能出现该错误。

Troubleshooting:
故障排查：

Set the Smooth factor to apply to be greater than the distance between the shapes on the overlap layer and rerun Abstract Generator. This forces the tool to create a single shape. See Retain Layout Information in the Abstract View.
将 Smooth factor to apply 设置为大于 overlap 层形状之间的距离，然后重新运行 Abstract Generator。这会强制工具创建单一形状。参见 在 Abstract 视图中保留版图信息。

To include shapes on the ignored boundary purpose, do one of the following:
如需包含被忽略的 boundary purpose 上的形状，请执行以下任一操作：

  • Explicitly include the purpose in the geometry specification in the Using geometry on layers field.
    For example, if you want the boundary shapes on M1 to be included in the overlap boundary creation, specify the following in the field instead of just M1:
    (M1 boundary) M1
    在 Using geometry on layers 字段的几何规范中显式包含 purpose。
    例如，如果你希望在 overlap boundary 创建中包含 M1 上的 boundary 形状，请在该字段中指定如下内容，而不是仅写 M1：
  • Remove boundary from the Ignored Purpose(s) field on the General tab (File – General options).
    Since this is a global , updating the Ignored Purpose(s) field in this way will affect all layer definitions. Therefore, choose this alternative only after due consideration.
    在 General 选项卡（File – General options）的 Ignored Purpose(s) 字段中移除 boundary。
    由于这是全局设置，以这种方式更新 Ignored Purpose(s) 会影响所有层定义。因此，仅在充分评估后再选择此方案。

ABS-14019

Message:
消息：

Cell name: net name has preset pin geometry which violates minimum area rules. You may want to option re-run the Extract step after ensuring that the Extract signal nets and Extract power nets options are turned on to create the correct geometry.
单元 name：网络 name 具有预设的引脚几何，违反最小面积规则。你可能需要在确保已开启 Extract signal nets 与 Extract power nets 选项以创建正确几何后，重新运行 Extract 步骤。

Description:
说明：

Because full geometry is not being performed, Abstract Generator has created a pin that does not satisfy the minimum area rules set for the layer in the technology file. See Select the Extract power nets option to run connectivity extraction for power nets.
由于未执行 full geometry，Abstract Generator 创建的引脚不满足 technology file 中为该层设置的最小面积规则。参见 Select the Extract power nets 选项以对电源网络执行连通性提取。

ABS-14020

Message:
消息：

Cell name: net name has boundary pin geometry which violates the minimum area rules. The Create boundary pins option has created pins that do not satisfy the minimum area rules in the technology file. You can inactivate the Create boundary pins option and rerun the command.
单元 name：网络 name 的边界引脚几何违反最小面积规则。Create boundary pins 选项创建了不满足 technology file 中最小面积规则的引脚。你可以停用 Create boundary pins 选项并重新运行命令。

ABS-14021

Message:
消息：

Cell name: net name has full shape pin geometry that violates the minimum area rules set in the technology file.
单元 name：网络 name 的 full shape 引脚几何违反 technology file 中设置的最小面积规则。

Description:
说明：

The pin geometry for a given layer must satisfy the minimum area rules defined for that layer in the technology file. If full geometry extraction is performed, and the pin still does not satisfy minimum area rules, it indicates a significant problem in the layout design.
某层的引脚几何必须满足 technology file 中为该层定义的最小面积规则。如果已经执行 full geometry 提取，而引脚仍然不满足最小面积规则，则表明版图设计存在较严重的问题。

ABS-14022

Message:
消息：

Cell name: geometry has been found abutting or extending past the prBoundary. As a result, the Create boundary pins option has been disabled.
单元 name：发现几何与 prBoundary 相贴或延伸超出 prBoundary。因此，Create boundary pins 选项已被禁用。

说明：

Because there is some geometry other than labels, power shapes, or abutments which extends beyond the place-and-route boundary, the Create boundary pins option has been disabled automatically. This indicates that there is a problem with the layout design.
由于存在除 labels、power shapes 或 abutments 之外的几何延伸超出 place-and-route 边界，Create boundary pins 选项已自动被禁用。这表明版图设计可能存在问题。

Description:

如果你在 Density 选项卡上使用 Layer Assignment for Metal Density Regions 表进行密度计算，并在表中指定了非金属层，则会出现此警告。Abstract Generator 会在密度计算中忽略该非金属层。

ABS-14033

Message:
消息：

Cell name: You are calculating metal density for the layer name layer. The technology file does not have a minimum density rule for this layer.
单元 name：你正在为 layer name 层计算金属密度。但 technology file 中未为该层定义最小密度规则。

Description:
说明：

This warning message appears when you try to calculate density for a metal layer for which no minimum density rule has been defined in the technology file. In the absence of the minimum density rule for the metal layer, the density information generated would not be useful.
当你尝试为 technology file 中未定义最小密度规则的金属层计算密度时，会出现此警告。缺少该金属层的最小密度规则时，生成的密度信息将没有实际意义。

To add minimum density rule for a metal layer in the technology file, see Virtuoso Technology Data ASCII Files Reference.
要在 technology file 中为金属层添加最小密度规则，参见 Virtuoso Technology Data ASCII Files Reference。

ABS-14035

Message:
消息：

Cell name: PR boundary is not rectilinear. Edges at non-orthogonal angles will be approximated to larger rectangular shapes, which might overlap other such rectangular shapes. Stair step approximation is currently not supported.
单元 name：PR boundary 不是直角多边形（rectilinear）。非正交角度的边将被近似为更大的矩形形状，可能与其他近似得到的矩形相互重叠。当前不支持 stair-step 近似。

Description:
说明：

Metal density calculations are based on the dimensions of rectangular density windows. However, when the edges of a PR boundary are non-orthogonal, Abstract Generator will extrapolate the shape to the closest possible rectangle. The resulting rectangular shape encloses regions outside the PR boundary and can overlap other such approximated rectangles.
金属密度计算基于矩形密度窗口的尺寸。然而，当 PR boundary 的边为非正交时，Abstract Generator 会将该形状外推到最接近的矩形。得到的矩形会包含 PR boundary 之外的区域，并可能与其他此类近似矩形发生重叠。

Troubleshooting:
故障排查：

Check the generated abstract to ensure that it meets the required guidelines.
请检查生成的 abstract，确保其符合所需规范。

ABS-14036

Message:
消息：

Cell name: does not have a valid PR boundary. The bounding box of the cell view will be used to generate density window(s).
单元 name：没有有效的 PR boundary。将使用 cell view 的 bounding box 生成密度窗口。

Description:
说明：

Reconsider the values selected for the Create boundary and Create overlap boundary options on the Boundary tab (Pins step) and Overlap tab (Abstract step), respectively, to obtain a valid PR boundary for the cell.
请分别重新检查 Boundary 选项卡（Pins 步骤）中的 Create boundary 选项与 Overlap 选项卡（Abstract 步骤）中的 Create overlap boundary 选项所选取的值，以获得该单元有效的 PR boundary。
