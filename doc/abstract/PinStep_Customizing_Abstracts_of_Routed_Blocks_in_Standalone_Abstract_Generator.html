Customizing Abstracts of Routed Blocks in Standalone Abstract Generator

在独立版抽象生成器中自定义 Routed Blocks 的抽象

To customize abstracts of routed blocks in Standalone Abstract Generator:

要在独立版抽象生成器中自定义 routed blocks 的抽象：

  1. Select one or more cells in the main window and choose Flow – Pins, or click the Pins icon.
    在主窗口中选择一个或多个单元，然后选择 Flow – Pins，或点击 Pins 图标。
    The Running step Pins form is displayed.
    将显示 Running step Pins 表单。
  2. Click the Blocks tab.
    点击 Blocks 选项卡。
  3. Select the Preserve local blockages in routed blocks field to control how Abstract Generator processes local blockages defined in the Blockage section in DEF 5.8. Local blockages do not have the +PUSHDOWN, +FILL, or +SLOT modifiers.
    选择 Preserve local blockages in routed blocks 字段，用于控制抽象生成器如何处理在 DEF 5.8 的 Blockage 章节中定义的本地阻塞（local blockages）。本地阻塞不包含 +PUSHDOWN、+FILL 或 +SLOT 修饰符。
  4. Select the Create power pins from routing field to control whether pins are created from the routing defined in the SPECIALNETS section of the DEF file.
    选择 Create power pins from routing 字段，用于控制是否根据 DEF 文件中 SPECIALNETS 章节定义的布线创建引脚。

When checked, Abstract Generator creates pins from the routing defined in the SPECIALNETS section for the layers specified in the Using geometry on layers field. It does this even if there are pins already defined in the Pins section.

启用后，抽象生成器会针对 Using geometry on layers 字段中指定的层，从 SPECIALNETS 章节定义的布线生成引脚。即使在 Pins 章节中已定义引脚，也会执行该操作。

  1. Click Run.
    The Percent Complete message box reports the progress of the step.
    点击 Run。
    Percent Complete 消息框会报告该步骤的进度。
