Specifying Connectivity Information in Designs

在设计中指定连通性信息

You can use the Running step Extract form to extract geometries on signal or power nets or to calculate process antenna information. You can specify connectivity information in a design using the General tab in the Running step Extract form.

你可以使用 Running step 的 Extract 表单在 signal 或 power 网络上抽取几何图形，或计算工艺天线信息。你可以在 Running step 的 Extract 表单中通过 General 选项卡来指定设计中的连通性信息。

To specify options in the General tab in the Running step Extract form:

在 Running step 的 Extract 表单中，指定 General 选项卡选项的方法如下：

  1. Choose Flow – Extract and click the General tab.
  2. Select Use net information from design if your design already contains connectivity information. If you select this option, Abstract Generator skips the extraction based on overlapping shapes and use the existing connectivity information in your design to create nets.
  3. Use the Layer connectivity field to specify the connectivity between layers. This allows you to specify the layer connectivity without having to add via definitions in the technology file.
    The Pin Geometry Restriction table provides you with finer control over final pin geometry.
  4. From a list of all the layers specified in the technology file, select those that you want to assign for pin geometry.
  5. Enter the Geometry Specification for the regions where pins are either to be restricted to or avoided.
  6. Choose whether pins are to be allowed or avoided (Allow or Avoid) in the geometry specified in the Geometry Specification field. The specified geometry specification (G-spec) describes the region where pins are to be allowed or avoided.
  7. In the Restrict column, select or deselect the button for adjusting pins and not for deleting the existing pins, which can slow down the performance of abstraction process. The red button indicates that the option is selected and the white button indicates that the option is not selected. To create the required pins, specify the geometry specification for the pin layers during the Extract step.
    By default, the Restrict column is used for both signal and power pins. You can choose whether only signal or power pins are to be restricted to the specified region or avoided. To do this:
    1. Set the following Shell environment variable before starting the Virtuoso session:
      setenv AllowAvoidSignalAndPowerPinsSeparately
    2. Set the following options of the absAbstract SKILL function to specify only power pins.
      absSetBinOption("Core" "AbstractAdjustAllowPowerPin" "(Metal1 (Metal1 andnot prBoundary boundary size -1)) ")
      absSetBinOption("Core" "AbstractAdjustAvoidPowerPin" "(Metal2 (Metal2 andnot prBoundary boundary size -1)) ")
    3. Set the following options of the absAbstract SKILL function to specify only signal pins.
      absSetBinOption("Block" "AbstractAdjustAllowPin" "(Metal1 (Metal1 andnot prBoundary boundary size -0.05)) ")
      absSetBinOption("Block" "AbstractAdjustAvoidPin" "(Metal1 (Metal1 andnot prBoundary boundary size -0.05)) ")
      If the AllowAvoidSignalAndPowerPinsSeparately environment variable is not set, the AbstractAdjustAllowPin and AbstractAdjustAvoidPin options are used to specify both signal and power pins.
  8. Select the Add, Edit, and Delete buttons and the G-Spec Builder Form in conjunction with the operators to work with the Layer Assignment for Pin Geometry table.
  1. 选择 Flow – Extract 并点击 General 选项卡。
  2. 如果你的设计已包含连通性信息，请选择 Use net information from design。选择该选项后，Abstract Generator 会跳过基于形状重叠的抽取，并使用设计中已有的连通性信息来创建 nets。
  3. 使用 Layer connectivity 字段指定层与层之间的连通关系。这样可以在无需在工艺文件中添加 via 定义的情况下指定层连通性。
    同时，Pin Geometry Restriction 表格可让你更精细地控制最终 pin 几何。
  4. 从工艺文件中指定的所有层列表中，选择你希望用于 pin 几何分配的层。
  5. 在 pins 需要被限制到的区域或需要避开的区域，填写 Geometry Specification。
  6. 在 Geometry Specification 字段指定的几何中，选择 pins 是允许还是避免（Allow 或 Avoid）。所指定的 geometry specification（G-spec）描述了 pins 允许或避免的区域。
  7. 在 Restrict 列中，选择或取消按钮，用于调整 pins 而非删除已有 pins（删除可能会降低抽象过程性能）。红色按钮表示已选中，白色按钮表示未选中。要创建所需 pins，请在 Extract 步骤中为 pin layers 指定 geometry specification。
    默认情况下，Restrict 列同时用于 signal 与 power pins。你可以选择仅对 signal pins 或仅对 power pins 进行区域限制/避免。方法如下：
    1) 在启动 Virtuoso 会话前设置 Shell 环境变量：AllowAvoidSignalAndPowerPinsSeparately。
    2) 通过 absAbstract SKILL 函数的选项指定仅 power pins。
    3) 通过 absAbstract SKILL 函数的选项指定仅 signal pins。若未设置 AllowAvoidSignalAndPowerPinsSeparately 环境变量，则 AbstractAdjustAllowPin 与 AbstractAdjustAvoidPin 选项同时用于指定 signal 与 power pins。
  8. 结合 operators 使用 Add、Edit 与 Delete 按钮，以及 G-Spec Builder Form 来编辑 Layer Assignment for Pin Geometry 表格。
