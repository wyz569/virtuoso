Calculation of Antenna Numbers for MUSTJOIN Terminals

MUSTJOIN 端子的天线号码计算

To calculate the antenna numbers of MUSTJOIN terminals, in the Extract step, Abstract Generator identifies disjoint groups of shapes extracted for nets in the layout. It then renames these terminals and sets the MUSTJOIN attribute on these terminals.

要计算 MUSTJOIN 端子的天线号码，在 Extract 步骤中，Abstract Generator 会识别版图中为网络抽取出的、彼此不连通的形状组。随后它会重命名这些端子，并在这些端子上设置 MUSTJOIN 属性。

Abstract Generator creates a separate terminal for each island. For example, for terminal A and n number of disjoint islands, the tool creates terminals A, A_mj1, A_mj2 …… A_mjn-1.

Abstract Generator 会为每个“岛”（island）创建一个独立端子。例如，对于端子 A 且存在 n 个不连通的岛，工具会创建端子 A、A_mj1、A_mj2 …… A_mjn-1。

For each island, Abstract Generator sets the antenna number to its corresponding terminal name. Abstract Generator calculates the antenna values by comparing different antenna numbers for each island individually. It does not compare antenna numbers across different islands.

对于每个岛，Abstract Generator 会将天线号码设置为对应的端子名称。Abstract Generator 会针对每个岛分别比较不同天线号码并计算天线值，而不会在不同岛之间比较天线号码。

You can use the following options to calculate antenna numbers for disjoint islands of a MUSTJOIN terminal:

你可以使用以下选项，为 MUSTJOIN 端子的不连通岛计算天线号码：

  • Either set the ExtractMustJoinTerminals option to true for the all the terminals or specify the terminal name in the ExtractMustJoinTerminals option.
    absSetBinOption( "<Bin Name>" "ExtractMustJoinAlways" "true") OR
    absSetBinOption( "<Bin Name>" "ExtractMustJoinTerminals" "terminal_name")
  • Select the Extract signal nets option on the Signal Tab in the Running step Extract form or use absSetBinOption to set the ExtractSig option to true.
    absSetBinOption( "<Bin Name>" "ExtractSig" "true")
  • Select one of the following antenna calculation options.
    • Calculate hierarchical antenna
    • Calculate input pin antenna
    • Calculate output pin antenna
    • Calculate inout pin antenna
    • Calculate antenna metal area
    • Calculate antenna metal side area
  • 将 ExtractMustJoinTerminals 选项对所有端子设置为 true，或在 ExtractMustJoinTerminals 选项中指定端子名称。
    absSetBinOption( "<Bin Name>" "ExtractMustJoinAlways" "true") OR
    absSetBinOption( "<Bin Name>" "ExtractMustJoinTerminals" "terminal_name")
  • 在 Running 步骤的 Extract 表单中，Signal 选项卡上选择 Extract signal nets 选项，或使用 absSetBinOption 将 ExtractSig 选项设置为 true。
    absSetBinOption( "<Bin Name>" "ExtractSig" "true")
  • 选择以下任一天线计算选项。
    • 计算层级天线（Calculate hierarchical antenna）
    • 计算输入引脚天线（Calculate input pin antenna）
    • 计算输出引脚天线（Calculate output pin antenna）
    • 计算双向引脚天线（Calculate inout pin antenna）
    • 计算天线金属面积（Calculate antenna metal area）
    • 计算天线金属侧面积（Calculate antenna metal side area）

Here, G1, G2, G3, G4, G5, and G6 represent the gate areas for the corresponding metal shapes. Cut or via layers are omitted for the sake of simplicity in the design.

其中，G1、G2、G3、G4、G5 和 G6 表示与相应金属形状对应的栅极面积。为简化示意，设计中省略了 cut 或 via 层。

When you select the Calculate antenna metal area option, Abstract Generator calculates the following values:

当你选择 Calculate antenna metal area 选项时，Abstract Generator 会计算以下数值：

  • ANTENNAPARTIALMETALAREA is the largest metal shape area for each layer.
  • ANTENNAGATEAREA is the minimum gate area among all the gates that are visible through each metal shape.
  • ANTENNAMAXAREACAR is the largest path among all the paths. It is calculated as area of metal layer divided by the area of gates visible to the shape.
  • ANTENNAPARTIALMETALAREA：每一层中最大的金属形状面积。
  • ANTENNAGATEAREA：通过每个金属形状可见的所有栅极中，最小的栅极面积。
  • ANTENNAMAXAREACAR：所有路径中最大的路径值，计算方式为金属层面积除以该形状可见的栅极面积。
