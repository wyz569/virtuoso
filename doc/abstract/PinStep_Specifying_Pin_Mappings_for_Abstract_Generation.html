Specifying Pin Mappings for Abstract Generation

为抽象生成指定引脚映射

To specify pin mapping settings in Standalone Abstract Generator:

要在独立版抽象生成器中指定引脚映射设置：

  1. Choose Flow – Pins or click the Pins icon.
    选择 Flow – Pins，或点击 Pins 图标。
    The Running step Pins form is displayed. The Map tab is the first tab in the form.
    将显示 Running step Pins 表单。Map 选项卡是该表单的第一个选项卡。
    On the Map tab, you can specify the text labels to be used for creating starting pin shapes for each of the nets to be extracted. You can also specify the pins that are power, ground, clock, analog, or output pins.
    在 Map 选项卡中，您可以为每个待提取的 net 指定用于创建起始引脚形状的文本标签；也可以指定哪些引脚属于 power、ground、clock、analog 或 output 引脚。
  2. In the Map text labels to pins field, specify the text labels in the layout view that are to be mapped to the pins on nets in the pins view. Specify the layer-purpose pairs based on which you want Abstract Generator to search for geometry of any given layer-purpose pair with a text label.
    在 Map text labels to pins 字段中，指定 layout view 中需要映射到 pins view 中各 net 引脚的文本标签。请指定 layer-purpose 对，抽象生成器将据此搜索带有文本标签的对应 layer-purpose 几何体。
  3. Specify the pin names in the Power pin names, Ground pin names, Clock pin names, Analog pin names, and Output pin names fields. Abstract Generator identifies the respective pin names based on the label strings in the abstract.
    在 Power pin names、Ground pin names、Clock pin names、Analog pin names 与 Output pin names 字段中指定引脚名称。抽象生成器会根据抽象中的标签字符串识别相应引脚名称。
  4. In the Exclude existing terminals field, specify a list of existing terminals that you want Abstract Generator to ignore.
    在 Exclude existing terminals 字段中，指定您希望抽象生成器忽略的现有端口列表。
  5. In the Exclude existing pins on layers field, specify a list of layers on which you want Abstract Generator to ignore the existing pins.
    在 Exclude existing pins on layers 字段中，指定您希望抽象生成器忽略现有引脚的层列表。
  6. In the Specify the top metal layer for cover blockage field, specify the metal layer to cover blockages.
    在 Specify the top metal layer for cover blockage 字段中，指定用于覆盖 blockage 的顶层金属层。
  7. Click Run.
    点击 Run。

The Percent Complete message box reports the progress of the step.

Percent Complete 消息框会报告该步骤的进度。
