Standalone Abstract Generator Environment Setup

独立版 Abstract Generator 环境设置

Abstract Generator reads a file named.abstractrc during the startup process. If you use the command line options to launch Abstract Generator, the tool first loads the.abstractrc file and then the replay file that has been specified using the -replay argument.

Abstract Generator 会在启动过程中读取名为 .abstractrc 的文件。如果使用命令行选项启动 Abstract Generator，工具会先加载 .abstractrc 文件，然后再加载通过 -replay 参数指定的 replay 文件。

When the tool starts, it searches for the.abstractrc file at the following locations in the order specified:

工具启动时，会按如下顺序在以下位置查找 .abstractrc 文件：

  • cds_install_dir/tools/dfII/local
    安装目录 cds_install_dir 下的 /tools/dfII/local
  • Current directory (.)
    当前目录（.）
  • Home directory (~)
    主目录（~）

You can modify the.abstractrc file to customize the tool for a group of users. You can also specify your custom standard cell SKILL code in the.abstractrc file so that Abstract Generator reads it every time you launch the tool. In addition, the .abstractrc file can enable you to run the required TCL or SKILL replay file when you launch the tool.

你可以修改 .abstractrc 文件，为一组用户定制该工具。你也可以在 .abstractrc 中指定自定义的 standard cell SKILL 代码，使 Abstract Generator 在每次启动时都读取它。此外，.abstractrc 还可用于在启动工具时运行所需的 TCL 或 SKILL replay 文件。

Do not set up library options in the.abstractrc file because they are overwritten when you open a library.

不要在 .abstractrc 文件中设置 library 选项，因为当你打开库时这些选项会被覆盖。
