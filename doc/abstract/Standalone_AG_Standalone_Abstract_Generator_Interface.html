Standalone Abstract Generator Interface

独立版 Abstract Generator 界面

The standalone Abstract Generator interface includes the following components to help you accomplish a wide range of tasks.

独立版 Abstract Generator 界面包含以下组件，可帮助你完成各类任务。

The following table describes the main components of the form.

下表描述了该窗体的主要组件。

UI Component
界面组件 		Description
说明

Main Window

主窗口

When you start Abstract Generator for the first time, the main window appears.

首次启动 Abstract Generator 时会显示主窗口。

The application title bar contains the name of the application and the name of the current library if one has been set. If no library has been opened, the title bar of the application displays no current library next to the name of the application, as is shown in the figure above.

应用标题栏包含应用名称，以及（如果已设置）当前库的名称。如果尚未打开任何库，标题栏会在应用名称旁显示 no current library，如上图所示。

Menu Bar

菜单栏

The menu bar provides access to all Abstract Generator operations. You can also perform some of these operations by quickly using the buttons on the toolbar below the menu bar.

菜单栏提供对 Abstract Generator 所有操作的访问。你也可以使用菜单栏下方工具栏上的按钮快捷执行其中部分操作。

Menu commands and toolbar buttons are grayed out when they are not available or do not apply in a particular scenario. For example, until you set a library you cannot import logical or layout information, so these and most of the other commands will be grayed out. Similarly, you cannot use the abstract generation steps until you have selected one or more cells in the Cell Preferences for Abstract Generation

当某些菜单命令和工具栏按钮不可用或不适用于当前场景时，它们会显示为灰色。例如，在设置库之前，你无法导入逻辑或版图信息，因此这些以及大多数其他命令都会变灰。类似地，在 Cell Preferences for Abstract Generation 中选中一个或多个 cell 之前，你无法使用 abstract 生成步骤。

Toolbar

工具栏

The toolbar is located below the pull-down menus and provides six button shortcuts to the most commonly used functions in Abstract Generator. Moving from left-to-right, the first three buttons are associated with functions in the File menu and the last three with functions in the Flow menu.

工具栏位于下拉菜单下方，提供 6 个按钮快捷方式，用于访问 Abstract Generator 中最常用的功能。从左到右，前三个按钮对应 File 菜单中的功能，后三个对应 Flow 菜单中的功能。

The left-to-right sequence of the buttons implies the basic flow in the abstract generation process, that is, set the current library, import data, and then run the abstract generation steps. You can use these functions in any permitted sequence to achieve more complex flows. Illegal button sequences are prevented by graying-out unavailable functions.

按钮从左到右的顺序暗示了 abstract 生成的基本流程：设置当前库、导入数据，然后运行 abstract 生成步骤。你可以在允许的范围内以任意顺序使用这些功能来实现更复杂的流程。不允许的按钮顺序会通过将不可用功能置灰来阻止。

  • Open Library: Specifies the library you want to process in Abstract Generator. See Opening a Library in Abstract Generator.
    Open Library：指定你希望在 Abstract Generator 中处理的库。参见 Opening a Library in Abstract Generator。
  • Import GDSII Data: Creates cellviews from existing layout information in GDSII format. See Importing GDSII Information in Abstract Generator.
    Import GDSII Data：从 GDSII 格式的现有版图信息创建 cellview。参见 Importing GDSII Information in Abstract Generator。
  • Import Logical Data: Creates cellviews from existing logical information. See Importing Logical Data in Abstract Generator.
    Import Logical Data：从现有逻辑信息创建 cellview。参见 Importing Logical Data in Abstract Generator。
  • Pins: Lets you view and modify the bin options relevant to the Pins step.
    Pins：用于查看和修改与 Pins 步骤相关的 bin 选项。
  • Extract: Lets you view and modify the bin options relevant to the Extract step.
    Extract：用于查看和修改与 Extract 步骤相关的 bin 选项。
  • Abstract: Lets you view and modify the bin options relevant to the Abstract step.
    Abstract：用于查看和修改与 Abstract 步骤相关的 bin 选项。

Bin Pane

Bin 面板

The exists on the left of the main application window below the menu bar and toolbar. The Bin pane displays the system bins and user bins, if any, and the number of cells in each bin. The number next to each bin name in the Bin pane indicates the number of cells in that bin. In the figure above, all the bins are empty. See Bin Preferences for Abstract Generation.

该区域位于主应用窗口左侧、菜单栏和工具栏下方。Bin 面板显示系统 bin 和（如有）用户 bin，以及每个 bin 中包含的 cell 数量。Bin 面板中每个 bin 名称旁的数字表示该 bin 中的 cell 数。上图中所有 bin 为空。参见 Bin Preferences for Abstract Generation。

Cell Pane

Cell 面板

The Cell pane is situated on the right of the main window below the menu bar and toolbar. It lists the cells contained in the selected bins and reports the status of those cells.

Cell 面板位于主窗口右侧、菜单栏和工具栏下方。它列出所选 bin 中包含的 cell，并报告这些 cell 的状态。

You need to select at least one cell before you can run any of the flow steps or view a status report on a cell. See Cell Preferences for Abstract Generation.

在运行任何流程步骤或查看某个 cell 的状态报告之前，你需要至少选择一个 cell。参见 Cell Preferences for Abstract Generation。

Log Window

日志窗口

The Log window is located in the bottom half of the Abstract Generator main window. The log displays all user interactions with Abstract Generator, including the display of version information on startup, error, warning, and info messages, and TCL/SKILL commands that have been input during a session.

日志窗口位于 Abstract Generator 主窗口的下半部分。日志会显示你与 Abstract Generator 的所有交互，包括启动时显示的版本信息、错误/警告/信息消息，以及会话期间输入的 TCL/SKILL 命令。

Above the Log window, Abstract Generator provides the interface language Interpreter Options, TCL or Skill. Skill is the default and recommended language option.

在日志窗口上方，Abstract Generator 提供解释器语言选项（Interpreter Options）：TCL 或 Skill。Skill 是默认且推荐的语言选项。

The LOG, ERROR, WARNING, and INFO entries in the Log window are color coded to make it easier to locate serious problems. The LOG and INFO entries are highlighted in BLUE, WARNING messages in ORANGE, and ERROR messages in RED.

日志窗口中的 LOG、ERROR、WARNING 和 INFO 条目采用颜色区分，便于定位严重问题。LOG 和 INFO 条目用蓝色高亮，WARNING 消息为橙色，ERROR 消息为红色。

Each ERROR, WARNING, and INFO message also has a unique message identifier, such as (ABS-246). In this identifier, “ABS” represents “Abstract Generator”, and “246” represents the unique number for identifying the message. All ERROR and WARNING message identifiers are highlighted in clickable BLUE hyperlinks. Clicking the identifier invokes the Doc Assistant in your browser window that displays extended description and possible workaround for the particular ERROR or WARNING message you clicked on.

每条 ERROR、WARNING 和 INFO 消息还有一个唯一的消息标识符，例如 (ABS-246)。其中 “ABS” 表示 “Abstract Generator”，“246” 是用于标识该消息的唯一编号。所有 ERROR 和 WARNING 的消息标识符都会以可点击的蓝色超链接高亮显示。点击标识符会在浏览器窗口中打开 Doc Assistant，展示你所点击的 ERROR 或 WARNING 消息的扩展说明及可能的绕过方法。

Command Entry Field

命令输入栏

The TCL/SKILL command entry field is at the bottom of the Log window and extends up to under the Command History window. In this field, at the abstract> prompt, you can manually enter a specific command function, for example absSelectAllBins, that tells Abstract Generator what operation to perform. The Command History window provides other quicker methods of entering command information in this field. See Abstract Generator SKILL Functions.

TCL/SKILL 命令输入栏位于 Log 窗口底部，并向上延伸至 Command History 窗口下方。在该输入栏的 abstract> 提示符处，你可以手动输入特定的命令函数（例如 absSelectAllBins），以告知 Abstract Generator 执行何种操作。Command History 窗口也提供了更快捷的方式来在该输入栏中填写命令信息。参见 Abstract Generator SKILL Functions。

Command History Window

命令历史窗口

The Command History window provides a list of all the TCL/SKILL commands that have been entered in the command entry field.

Command History 窗口列出了所有在命令输入栏中输入过的 TCL/SKILL 命令。

This window helps you save time in re-typing a command. Double-click to select a command in this window, then place your cursor over the Command Entry Field, and click the middle mouse button to copy the command in the command entry field.

该窗口可帮助你节省重复输入命令的时间。在此窗口中双击选择某条命令，然后将光标移到命令输入栏上，在目标输入栏中点击鼠标中键即可复制该命令。

Alternatively, you can also scroll through the commands listed in the Command History window by using the cursor keys on the keyboard, with whatever command you have highlighted appearing in the command entry field ready for use.

另外，你也可以使用键盘方向键在 Command History 窗口中滚动浏览命令列表，被高亮的命令会显示在命令输入栏中，随时可用。

Percent Complete

完成百分比（Percent Complete）

The Percent Complete message box lets you monitor the progress of the current step.

Percent Complete 消息框可用于监控当前步骤的进度。

The label on the Percent Complete message box tells you what operation is currently being tracked, for example Running Extract as in the figure below, while the bar and percentage give you a visual indication of the progress.

Percent Complete 消息框上的标签会告诉你当前正在跟踪的操作，例如下图中的 Running Extract；进度条与百分比则为你提供直观的进度指示。

Use the Stop button in the Percent Complete message box to stop the current operation. Abstract Generator prompts you to confirm that you stop the operation.

使用 Percent Complete 消息框中的 Stop 按钮可停止当前操作。Abstract Generator 会提示你确认是否停止。

Depending on the step that is running, Abstract Generator might not be able to stop the operation immediately. In this case, it will proceed until the next safe point before stopping. You can ascertain the current state of your library from the status indicators in the Cell pane, and from the log file saved in the run directory.

根据正在运行的步骤不同，Abstract Generator 可能无法立即停止该操作。在这种情况下，它会继续运行直到下一个安全点再停止。你可以通过 Cell 面板中的状态指示，以及保存在运行目录中的日志文件来确认库的当前状态。

When you run any abstract generation flow step, Abstract Generator lets you monitor the progress of the step through a message box.

当你运行任意 abstract 生成流程步骤时，Abstract Generator 会通过消息框让你监控该步骤的进度。

Abstract Generator lets you copy and paste text between GUI fields and tables. To copy text from a GUI field, click-and-drag to select the required text. To paste the text in its new location, click the middle-mouse button in the target field or table cell.

Abstract Generator 支持在 GUI 字段与表格之间复制/粘贴文本。要从 GUI 字段复制文本，请点击并拖动选择所需文本；要粘贴到新位置，请在目标字段或表格单元格中点击鼠标中键。

To copy text from a table cell, click in the table cell containing the text to be copied. The text for the entire cell is attached to the clipboard until another GUI element is selected. To paste the text in its new location, click the middle-mouse button in the target field or table cell.

要从表格单元格复制文本，请点击包含目标文本的单元格。整个单元格的文本会附加到剪贴板，直到你选择了另一个 GUI 元素。要粘贴到新位置，请在目标字段或表格单元格中点击鼠标中键。

Partial text selection for copy and paste is available only in non-table GUI fields.

复制/粘贴时的部分文本选择仅在非表格类 GUI 字段中可用。
