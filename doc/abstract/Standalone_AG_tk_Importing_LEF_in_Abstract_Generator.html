Importing LEF in Abstract Generator

在 Abstract Generator 中导入 LEF

The Import LEF form lets you create cellviews from LEF data. This is used when creating blocks from DEF. The LEF data for the leaf cells should be imported, followed by the DEF data for the associated block.

Import LEF 表单用于从 LEF 数据创建 cellview。在从 DEF 创建 block 时会使用该功能。应先导入 leaf cell 的 LEF 数据，然后再导入对应 block 的 DEF 数据。

  1. Selecting File – Import – LEF displays the Import LEF form.
  2. The LEF Filenames field specifies the LEF files to import. You can type the name manually in the field or Browse for existing files with the.lef extension in the current directory.
  3. The View field specifies the cellview to which a LEF macro will be saved. The default view is abstract but this can be changed so that the LEF macro is saved to another view, such as the layout view.
  4. The subsection techControl, added to the technology file for incremental technology database support, necessitates the specification of a set of ordered reference libraries to allow inheritance from these libraries.
    Abstract Generator allows you to specify one or more valid reference technology libraries in the Technology Reference Library Name field. The specified referenced technology libraries must be present in the cds.lib file and must be readable.
  5. Select Overwrite to overwrite the current technology file if the LEF file to be imported contains one. This option is off by default.
    All kinds of LEF files can be imported, ones with both technology and geometry information and also the ones with only technology or only geometry information.
    You cannot import a technology LEF file if the default technology file, cdsDefTechLib, is already attached to a cell library. If you attempt to do this, an error message will display.
  6. In Library Name, specify the name of the LEF library that needs to be imported.
    The library and its associated technology file are loaded into the current abstract session. At this point, the corresponding GDS file, if available, is also read.
    When specifying the Library Name:
    • If a library is already loaded in the current abstract session, then the name of the currently open library is displayed in the Library Name field. Either retain the same library name or specify a different value.
    • If you have created a new library, then the name of the newly created library is displayed in the Library Name field. Either retain the same library name or specify a different value.
    • If no library is currently loaded in AG, and user wants to create new library using the Import LEF form, then it is mandatory to specify the library name along with the LEF file name. Else an error message is displayed and the Import LEF operation fails.
  7. Click OK.
  1. 选择 File – Import – LEF 将显示 Import LEF 表单。
  2. LEF Filenames 字段用于指定要导入的 LEF 文件。你可以在该字段中手动输入文件名，或点击 Browse 在当前目录中选择扩展名为 .lef 的现有文件。
  3. View 字段用于指定 LEF macro 要保存到的 cellview。默认 view 为 abstract，但你也可以修改为其它 view，例如 layout view。
  4. 为支持增量式工艺数据库（incremental technology database），工艺文件中新增的 techControl 子段要求指定一组按顺序排列的 reference library，以便从这些库继承信息。
    Abstract Generator 允许你在 Technology Reference Library Name 字段中指定一个或多个有效的 reference technology library。所指定的 reference technology library 必须存在于 cds.lib 文件中，并且必须可读。
  5. 如果要导入的 LEF 文件包含工艺文件，选择 Overwrite 可覆盖当前工艺文件。该选项默认关闭。
    可导入多种类型的 LEF 文件，包括同时包含工艺与几何信息的 LEF，以及仅包含工艺信息或仅包含几何信息的 LEF。
    如果默认工艺文件 cdsDefTechLib 已经附加到某个 cell library，则无法导入 technology LEF 文件。若尝试导入，将显示 error 消息。
  6. 在 Library Name 中指定需要导入的 LEF library 名称。
    该 library 及其关联的工艺文件将被加载到当前 abstract session 中。此时，如果有对应的 GDS 文件，也会被读取。
    在指定 Library Name 时：
    • 如果当前 abstract session 已加载某个 library，则 Library Name 字段会显示当前打开的 library 名称。你可以保留该名称，或指定其它名称。
    • 如果你创建了新 library，则 Library Name 字段会显示新创建的 library 名称。你可以保留该名称，或指定其它名称。
    • 如果 AG 当前未加载任何 library，而你希望使用 Import LEF 表单创建新 library，则必须同时指定 library 名称与 LEF 文件名。否则将显示 error 消息，Import LEF 操作会失败。
  7. 点击 OK。

Abstract Generator opens the specified library. So, if you specify a library name other than the currently loaded library, then the newly created library is loaded.

Abstract Generator 会打开所指定的 library。因此，如果你指定的 library 名称与当前已加载的 library 不同，则会加载新创建的 library。
