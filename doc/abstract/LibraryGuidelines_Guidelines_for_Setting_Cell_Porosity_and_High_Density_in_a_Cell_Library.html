Guidelines for Setting Cell Porosity and High Density in a Cell Library

单元库单元孔隙率与高密度设置指南

Cells are more porous if there is free routing resource to route over the cell. A porous library allows high core utilizations.

当单元上方存在可用的布线资源可以跨单元布线时，单元会更“多孔”（porous）。一个多孔的库允许更高的核心区利用率（core utilization）。
