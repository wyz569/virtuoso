Calculating Metal Layer Density
计算金属层密度

You can generate metal density information for abstracts in LEF 5.8. The density value in LEF helps in verifying metal density fabrication rules early in the design cycle without having to replace the abstracts with the layouts. This information in LEF can reduce the memory requirements and increase the speed of metal fill tools and aid these tools to analyze and fix the designs using abstracts.
你可以在 LEF 5.8 中为 abstract 生成金属密度信息。LEF 中的密度数值有助于在设计周期早期验证金属密度制造规则，而无需用版图替换 abstract。LEF 中的这些信息还可以降低内存需求、提升金属填充工具的速度，并帮助这些工具基于 abstract 分析与修复设计。

To calculate the metal layer density:
要计算金属层密度：

  1. Choose Flow – Abstract and click the Density tab in the Running step Abstract for the selected cell(s) form.
    选择 Flow – Abstract，并在所选 cell(s) 的 Running step Abstract 窗体中单击 Density 选项卡。
    The options on this tab provide specifications to Abstract Generator for calculating metal density (in percentage) for macros.
    该选项卡上的设置会为 Abstract Generator 提供对宏单元计算金属密度（百分比）的相关规格。
  2. Select Calculate metal density to specify that metal density information is to be generated for the selected cell(s).
    选择 Calculate metal density，以指定为所选 cell(s) 生成金属密度信息。
    Now, you can specify the details to enable Abstract Generator in determining the metal layers and metal geometries for which density calculation needs to be performed.
    然后，你可以进一步指定细节，使 Abstract Generator 确定需要执行密度计算的金属层与金属几何。
  3. You can use the same metal layers and their corresponding geometry specifications as you would have specified for signal nets, power nets, or antenna data extraction in the Extract step. To do this, select one of the following options on the Density tab:
    你可以复用在 Extract 步骤中为信号网、电源网或天线数据抽取所指定的金属层及其几何规格。为此，请在 Density 选项卡上选择以下任一选项：
    • Use layer assignment for signal extraction
      使用信号抽取的层分配
    • Use layer assignment for antenna extraction
      使用天线抽取的层分配
    • Use layer assignment for power extraction
      使用电源抽取的层分配
  4. You can specify a different set of geometry specifications for metal layers by using the Layer Assignment for Metal Density Regions table. To use the geometry specifications from this table, ensure that none of the three layer assignment options is selected.
    你也可以通过 Layer Assignment for Metal Density Regions 表为金属层指定另一套几何规格。若要使用该表中的几何规格，请确保上面三个 layer assignment 选项均未被选中。
  5. Use the following fields to specify the same width and height value for all the layers:
    使用以下字段为所有层指定相同的窗口宽度与高度：
    • Default density window width
      默认密度窗口宽度
    • Default density window height
      默认密度窗口高度
  6. Click Run.
    单击 Run。
