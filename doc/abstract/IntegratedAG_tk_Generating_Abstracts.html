Generating Abstracts

生成 Abstract

You can load values in the Abstract Generator form, run the Abstract Generator steps and view the results during the abstract generation process. When all the options are loaded, the Abstract Generator form features separate sections for each of the abstract generation steps.

你可以在 Abstract Generator 表单中加载参数，运行 Abstract Generator 各步骤，并在 abstract 生成过程中查看结果。当所有选项都加载后，Abstract Generator 表单会为每个 abstract 生成步骤提供独立的区域。

To generate abstracts:

要生成 abstract：

  1. In the CIW, choose Tools - Abstract Generator.
    The Abstract Generator form is displayed.

    在 CIW 中选择 Tools - Abstract Generator，将显示 Abstract Generator 表单。
  2. Initialize the fields in the Design Information section and load the options file.
    初始化 Design Information 区域中的字段，并加载选项文件。
  3. In the Pins section, you can use the progressive disclosure arrow to reveal or hide the options.
    在 Pins 区域中，可使用渐进式披露箭头显示或隐藏选项。
    The integrated Abstract Generator preserves local blockages and creates pins from labels during the Pins step.
    在 Pins 步骤中，集成版 Abstract Generator 会保留本地 blockage，并从 label 创建引脚。
  4. In the Extract section, you can extract new pins by tracing the physical connections starting from pins created in the Pins step. Antenna numbers are also calculated based on the options selected. You can use the progressive disclosure arrow to reveal or hide the options.
    在 Extract 区域中，你可以从 Pins 步骤创建的引脚出发，沿物理连接进行追踪来提取新引脚。还会根据所选选项计算天线数量。可使用渐进式披露箭头显示或隐藏选项。
    • Choose whether you want to extract connectivity information for Signal, Power, or both types of nets.
      选择要为 Signal、Power 或两类网络同时提取连通性信息。
    • Select Connectivity to specify the connectivity between layers. You can specify the layer connectivity without having to add via definitions in the technology file.
      选择 Connectivity 以指定层之间的连通关系。无需在工艺文件中添加 via 定义，也可以指定层连通性。
    • Select Calculate Antenna to create process antenna information for custom blocks and standard cells.
      选择 Calculate Antenna，为自定义 block 与标准单元创建工艺天线信息。
    • Select Gate and Drain text boxes to assign layers to antenna regions to identify the gate and drain regions and to enable antenna calculation.
      选择 Gate 与 Drain 文本框，为天线区域分配层以识别栅极与漏极区域，并启用天线计算。
    • Select Signal Layers to list all signal layers to be extracted. Select Use Signal GSpec for Power GSpec to extract the geometry specifications for these layers.
      选择 Signal Layers 以列出所有需要提取的信号层。选择 Use Signal GSpec for Power GSpec 以提取这些层的几何规格。
    • Select Pin Layers to list all the layers on which pins need to be created for signal nets.
      选择 Pin Layers 以列出所有需要为信号网络创建引脚的层。
    • Select Power Layers to list all power layers to be extracted. Select Use Signal GSpec for Power GSpec to extract the geometry specifications for these layers.
      选择 Power Layers 以列出所有需要提取的电源层。选择 Use Signal GSpec for Power GSpec 以提取这些层的几何规格。
    • Select Pin Layers to list all the layers on which pins need to be created for power nets.
      选择 Pin Layers 以列出所有需要为电源网络创建引脚的层。
  5. Abstract is the third and final step of the abstract generation process. You can use the progressive disclosure arrow to reveal or hide the options.
    Abstract 是 abstract 生成流程的第三步也是最后一步。可使用渐进式披露箭头显示或隐藏选项。
    • Use Create Boundary Pins to create square pins at the boundary from the extracted pin geometries. You can create boundary pins for Signal nets, Power nets, or both.
      使用 Create Boundary Pins，可基于已提取的引脚几何在边界处创建方形引脚。可为 Signal 网络、Power 网络或两者同时创建边界引脚。
    • Select Create Overlap Boundary to specify whether a rectilinear PR boundary (overlap) should be generated during abstraction.
      选择 Create Overlap Boundary，指定在抽象过程中是否生成直角 PR boundary（overlap）。
    • Select Signal Grouping and Power Grouping to control how the pin geometries are grouped for corresponding signal and P/G nets.
      选择 Signal Grouping 与 Power Grouping，以控制对应信号网络与 P/G 网络的引脚几何如何分组。
    • In the Cover Blockages field, specify the layers to be considered while creating cover blockages.
      在 Cover Blockages 字段中，指定创建 cover blockage 时要考虑的层。
    • In the Pin CutOut field, specify the layers on which pin cutouts need to be created. Pin cutouts are applicable for all types of blockages: cover, detailed, and shrink.
      在 Pin CutOut 字段中，指定需要创建 pin cutout 的层。Pin cutout 适用于所有类型的 blockage：cover、detailed 与 shrink。
    • Select Fracture Blockages and Fracture Pins options to generate only rectangular geometries for pins and blockages in the final abstract view.
      选择 Fracture Blockages 与 Fracture Pins 选项，在最终 abstract 视图中仅为引脚与 blockage 生成矩形几何。
  6. When you are satisfied with the options settings, use the above four flow steps to generate abstracts for the selected cells. You can run the steps either one at a time or all at once for any or all of the cells.
    当你对选项设置满意后，使用以上四个流程步骤为所选 cell 生成 abstract。你可以对任意或所有 cell 逐步运行，也可以一次性运行所有步骤。
  7. After updating values in the Design Information and Extract sections, click Generate Abstract to run Abstract Generator.
    更新 Design Information 与 Extract 区域中的参数后，单击 Generate Abstract 以运行 Abstract Generator。

The Abstract Log window is displayed.

将显示 Abstract Log 窗口。
