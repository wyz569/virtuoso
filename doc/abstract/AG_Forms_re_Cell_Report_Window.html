Cell Report Window
Cell 报告窗口

Use the Cell Report Window to view and change the properties on cells.

使用 Cell Report Window 查看并更改单元（cell）的属性。

Field
字段 		Description
说明

CellName

CellName：单元名称。

Displays a list of all the cells that are selected in the Cell(s) field in the Design Information section of the Abstract Generator form.

显示 Abstract Generator form 的 Design Information 区域中 Cell(s) 字段里所选的所有单元列表。

Status

Status：状态。

Displays the status of the cells, green indicates no errors or warnings, orange indicates warnings, and red indicates errors during abstract generation.

显示单元的状态：绿色表示无错误或警告，橙色表示有警告，红色表示在 abstract 生成过程中发生错误。

Errors

Errors：错误数。

Displays the number of errors that were reported during abstract generation.

显示在 abstract 生成过程中报告的错误数量。

Warnings

Warnings：警告数。

Displays the number of warnings that were reported during abstract generation.

显示在 abstract 生成过程中报告的警告数量。

Report

Report：报告。

Displays the View button against every cell. Click the button to view detailed information about the abstract generation process, including the time taken for abstract generation, types of blockages created on different layers, and the complete list of errors and warnings that were reported.

在每个单元对应位置显示 View 按钮。点击该按钮可查看 abstract 生成过程的详细信息，包括生成耗时、在不同层创建的 blockage 类型，以及所报告的错误与警告完整列表。
