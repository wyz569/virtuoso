Specifying Design Information in the Abstract Generator

在 Abstract Generator 中指定设计信息

You can load values in the Abstract Generator form, run the Abstract Generator steps and view the results during the abstract generation process. To initialize the fields in the Abstract Generator form:

你可以在 Abstract Generator 表单中加载参数，运行 Abstract Generator 各步骤，并在 abstract 生成过程中查看结果。要初始化 Abstract Generator 表单中的字段：

  1. In the CIW, choose Tools - Abstract Generator.
    The Abstract Generator form is displayed.
    在 CIW 中，选择 Tools - Abstract Generator。
    将显示 Abstract Generator 表单。
  2. Select a library.
    选择一个库。
    The library list is read in from the cds.lib file located in the run directory, and libraries are listed in an alphabetical order. When you select a library, the Cell(s) list is automatically populated.
    库列表从运行目录中的 cds.lib 文件读入，并按字母顺序列出。选择库后，Cell(s) 列表会自动填充。
  3. In the Filter Cells field, you can filter out cells based on their names. For example, type top to filter out cells that contain the string in their name.
    在 Filter Cells 字段中，你可以按名称过滤 cell。例如，输入 top 以筛选名称中包含该字符串的 cell。
  4. From the Cell(s) list, select the required cells. Use one of the following selection methods:
    从 Cell(s) 列表中选择所需 cell。可使用以下任一选择方法：
    • Select one or multiple cells by clicking their names.
      单击名称以选择一个或多个 cell。
    • Select multiple consecutive cells by clicking a cell and dragging the cursor across all the cells to be selected without releasing the mouse button. Release the mouse button after all the required cells have been selected.
      单击一个 cell 并拖动鼠标（不释放按键）跨过要选择的所有 cell，可选择多个连续 cell。选择完所需 cell 后释放鼠标按键。
    • Select all cells by using the Ctrl+A bindkey.
      使用 Ctrl+A 快捷键选择所有 cell。

    The number of cells selected is displayed in the status bar.
    所选 cell 数量会显示在状态栏中。
    To deselect cells:
    取消选择 cell：
    • Click the individual cells to be deselected.
      单击要取消选择的单个 cell。
    • To deselect all the cells at one go, use the Ctrl+D bindkey.
      要一次性取消选择所有 cell，请使用 Ctrl+D 快捷键。
  5. In the View field, specify the view name in which you want to create abstracts.
    在 View 字段中，指定你要创建 abstract 的 view 名称。
  6. From the Design Type drop-down list, select a design type. Design type indicates the type of cells to be processed in this abstract run: Block (default), Core, IO, or Corner.
    在 Design Type 下拉列表中选择设计类型。Design type 指示本次 abstract 运行要处理的 cell 类型：Block（默认）、Core, IO 或 Corner。
  7. (Optional) Specify a Top Metal layer. If you specify a top metal layer, the layers listed in the Extract and Abstract steps are automatically restricted to the specified top metal layer. This means that abstract shapes are generated only for objects on the specified layer and its lower layers, and not for any others. For example, if Top Metal is set to M3, then the other layer options are reset to include only layers M3 and its lower layers. Abstract shapes are generated only for objects on these layers.
    （可选）指定一个 Top Metal 层。指定 Top Metal 后，Extract 与 Abstract 步骤中列出的层会自动限制到该 Top Metal 层。也就是说，只会对指定层及其更低层上的对象生成 abstract 形状，而不会包含其他层。例如，如果 Top Metal 设为 M3，则其他层相关选项会被重置为仅包含 M3 及其更低层；abstract 形状只会针对这些层上的对象生成。
  8. In the Options File field, specify the path from where Abstract Generator loads the options.
    在 Options File 字段中，指定 Abstract Generator 加载选项的路径。
  9. Click Load Options.
    单击 Load Options。

Abstract Generator loads the options file in the following order:

Abstract Generator 按以下顺序加载选项文件：

  • The options file (.abstract.options) from the <current working directory>/.abstract/<library name> directory is loaded. If not available in the above location, Abstract Generator reads the file first from the attached technology library directory and then from the design library directory.
    首先加载位于 <current working directory>/.abstract/<library name> 目录中的选项文件（.abstract.options）。如果上述位置不存在该文件，Abstract Generator 会先从所附加的工艺库目录读取，然后从设计库目录读取。
  • The file specified in the Options File field in the Abstract Generator form is loaded. If the same options are available in the next file loaded, the options are overwritten accordingly.
    然后加载在 Abstract Generator 表单的 Options File 字段中指定的文件。如果后续加载的文件中包含相同选项，则会相应覆盖这些选项。
