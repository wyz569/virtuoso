Troubleshoot Technology Issues

排查 Technology 问题

This section lists the common problems found in technology files in the Virtuoso Studio design environment and provides information about how to fix these to enable Abstract Generator to run.

本节列出在 Virtuoso Studio 设计环境的 technology file 中常见的问题，并提供修复方法，以便 Abstract Generator 能够正常运行。

ABS-10034

ABS-10034

A list of errors is displayed in the technology file. There are a number critical checks performed by Abstract Generator on start-up, among them a validity check on the technology data associated with a design. If any of these checks fails, Abstract Generator issues an appropriate error message. Use the Technology File Manager to resolve these errors before proceeding.

technology file 中显示了一组错误。Abstract Generator 在启动时会执行多项关键检查，其中包括对与设计关联的 technology 数据进行有效性检查。如果任一检查失败，Abstract Generator 会给出相应的错误消息。继续操作前，请使用 Technology File Manager 解决这些错误。

ABS-10042

ABS-10042

Technology initialization failed because the name layer with the value layer number and the name layer with the value layer number have the same name.  The same layer name cannot be associated with two layer numbers. Each layer has an associated layer name and is assigned a unique layer number in techLayers in the layerDefinitions section of the technology file. Rectify the error in the technology file and then try again.

Technology 初始化失败，因为两个不同 layer number 对应的 name layer 使用了相同的名称。同一个 layer name 不能同时关联到两个 layer number。每个 layer 都有一个关联的 layer name，并且在 technology file 的 layerDefinitions 章节的 techLayers 中分配唯一的 layer number。请在 technology file 中修正该错误后重试。

ABS-10044

ABS-10044

Failed to perform antennaSideArea calculations because the name layer does not have a thickness value specified. To resolve this issue:

无法执行 antennaSideArea 计算，因为该 name layer 未指定 thickness 值。可按以下方式解决：

  1. Specify the thickness value in the antenna subsection of the foundry constraint group of the technology file.
    在 technology file 的 foundry constraint group 的 antenna 子章节中指定 thickness 值。
  2. To perform antenna side area factor or ratio calculations, set a thickness value for the layer in the antenna subsection of foundry constraint group.
    若要执行 antenna side area 的因子或比值计算，请在 foundry constraint group 的 antenna 子章节中为该 layer 设置 thickness 值。

ABS-10050

ABS-10050

Failed to create the name, purpose layer-purpose pair in the technology file. Ensure that you have permissions to write to the technology file and then try again. To do this:

无法在 technology file 中创建 name、purpose 这组 layer-purpose pair。请确认你对该 technology file 具有写入权限，然后重试。可按以下方式处理：

  1. Specify the layer-purpose pair information in the techPurposes construct in the layerDefinitions section during the abstract generation process.
    在生成 abstract 的过程中，于 layerDefinitions 章节的 techPurposes 结构中指定 layer-purpose pair 信息。
    If missing, you can append this information to the technology file.
    如果缺失，也可以将该信息追加到 technology file。
  2. If write permissions exist on the technology file, Abstract Generator will automatically add the missing layer-purpose pair. However, you would not be able to update the technology file if you do not have the write permission on the file, which is when Abstract Generator issues this message.
    如果 technology file 具备写入权限，Abstract Generator 会自动补全缺失的 layer-purpose pair。若你没有该文件的写入权限，将无法更新 technology file，Abstract Generator 就会报出此消息。
  3. Change the permission setting of the technology file or contact the person responsible for updating the technology file.
    修改 technology file 的权限设置，或联系负责更新 technology file 的人员。
  4. Use the Technology File Manager to add the missing layer-purpose definition to the technology file prior to invoking Abstract Generator.
    在启动 Abstract Generator 之前，使用 Technology File Manager 将缺失的 layer-purpose 定义补充到 technology file。

ABS-10053

ABS-10053

Abstract Generator has failed to set the required property. If you are unable to isolate the problem, contact your Cadence Customer Support representative for help.

Abstract Generator 无法设置所需属性。如果你无法定位问题原因，请联系 Cadence 客户支持代表获取帮助。

ABS-10054

ABS-10054

Failed to initialize Abstract Generator because either the name layer is not defined in the standardViaDefs subsection of the viaDefs section or the layer function has not been identified as 'cut' in the functions subsection of the layerRules section. Ensure that the layer is correctly defined in both standardViaDefs and functions subsection and then try again.

Abstract Generator 初始化失败，原因可能是：viaDefs 章节的 standardViaDefs 子章节未定义 name layer，或 layerRules 章节的 functions 子章节未将该 layer function 标识为 cut。请确保在 standardViaDefs 与 functions 子章节中均正确完成定义后重试。

  1. You need to define via layers in the standardViaDefs section and as ‘cut’ in the functions subclass of the layerRules section. This error will be generated if the via layer is not defined in any one of these.
    你需要在 standardViaDefs 中定义 via layers，并在 layerRules 的 functions 子章节中将其定义为 cut。如果任一处缺失该 via layer 的定义，就会触发此错误。
  2. Using the Technology File Manager, check the standardViaDefs section and the functions subsection in the layerRules section in the technology file.
    使用 Technology File Manager 检查 technology file 中的 standardViaDefs 章节，以及 layerRules 章节下的 functions 子章节。
  3. Update the section in which the via layer definition is missing.
    在缺失 via layer 定义的章节中补全相关配置。

ABS-10055

ABS-10055

Failed to create the name site in the technology library name technology file. Abstract Generator tried unsuccessfully to create a site in the OpenAccess technology file, tech.db. The exception message issued by OpenAccess indicates the reason for the failure. For example, you might not have permission to update the tech.db file.

无法在 technology library name 的 technology file 中创建 site name。Abstract Generator 尝试在 OpenAccess technology file tech.db 中创建 site 但失败。OpenAccess 抛出的异常消息会指明失败原因。例如，你可能没有权限更新 tech.db 文件。

ABS-19006

ABS-19006

The routing direction for layer layerName has not been specified. Specify the appropriate direction in the routingDirections sub-section of layerRules section of the technology file.

未指定 layer layerName 的 routing direction。请在 technology file 的 layerRules 章节下的 routingDirections 子章节中指定正确的方向。
