Import LEF Form

导入 LEF 表单

Use the Import LEF form to create cellviews from LEF data.

使用 Import LEF 表单可从 LEF 数据创建 cellview。

Field
字段 		Description
说明

LEF Filenames
LEF 文件名

Specifies the LEF files to import. You can type the name manually in the field or Browse for existing files with the .lef extension in the current directory.

指定要导入的 LEF 文件。你可以在字段中手动输入文件名，或通过 Browse 在当前目录中查找扩展名为 .lef 的现有文件。

View
视图

Specifies the cellview to which a LEF macro will be saved. The default view is abstract but this can be changed so that the LEF macro is saved to another view, such as the layout view.

指定 LEF macro 将保存到哪个 cellview。默认视图为 abstract，但可以更改为将 LEF macro 保存到其他视图（例如 layout 视图）。

Technology Reference Library Name
工艺参考库名称

Allows you to specify one or more valid reference technology libraries. The specified referenced technology libraries must be present in the cds.lib file and must be readable.

允许指定一个或多个有效的参考工艺库。所指定的参考工艺库必须出现在 cds.lib 文件中且可读。

Overwrite
覆盖

Enables Abstract Generator to overwrite the current technology file if the LEF file to be imported contains one. This option is off by default. All kinds of LEF files can be imported, ones with both technology and geometry information and also the ones with only technology or only geometry information.

如果要导入的 LEF 文件包含技术文件，则允许 Abstract Generator 覆盖当前技术文件。该选项默认关闭。可以导入各种类型的 LEF 文件：同时包含技术与几何信息的文件，以及仅包含技术或仅包含几何信息的文件。

You cannot import a technology LEF file if the default technology file, cdsDefTechLib, is already attached to a cell library. If you attempt to do this, an error message will display.

如果默认技术文件 cdsDefTechLib 已附加到某个单元库，则无法导入技术 LEF 文件。若尝试执行此操作，将显示错误消息。

Library Name
库名称

Lets you specify the name of the LEF library that needs to be imported. The library and its associated technology file are loaded into the current abstract session. At this point, the corresponding GDS file, if available, will also be read.

用于指定需要导入的 LEF 库名称。该库及其关联的技术文件会被加载到当前 abstract 会话中。此时，如果存在对应的 GDS 文件，也会被读取。

When specifying the library name:

指定库名称时：

  • If a library is already loaded in the current abstract session, then the name of the currently open library is displayed in the Library Name field. Either retain the same library name or specify a different value.
    如果当前 abstract 会话中已加载某个库，则当前打开库的名称会显示在 Library Name 字段中。你可以保留该库名，也可以指定不同的值。
  • If you have created a new library, then the name of the newly created library is displayed in the Library Name field. Either retain the same library name or specify a different value.
    如果你创建了新库，则新创建库的名称会显示在 Library Name 字段中。你可以保留该库名，也可以指定不同的值。
  • If no library is currently loaded in AG, and user wants to create new library using the Import LEF form, then it is mandatory to specify the library name along with the LEF file name. Else an error message is displayed and the Import LEF operation fails.
    如果 AG 当前未加载任何库，并且用户希望使用 Import LEF 表单创建新库，则必须同时指定库名称与 LEF 文件名；否则会显示错误消息，Import LEF 操作失败。
  • When you click OK, Abstract Generator opens the specified library. So, if you specify a library name other than the currently loaded library, then the newly created library is loaded.
    当你点击 OK 时，Abstract Generator 会打开指定的库。因此，如果指定的库名不同于当前已加载的库，则会加载新创建的库。

Alternatively use option LEFLibraryName.

也可以使用选项 LEFLibraryName。
