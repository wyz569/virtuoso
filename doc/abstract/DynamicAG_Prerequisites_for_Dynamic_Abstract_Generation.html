Prerequisites for Dynamic Abstract Generation

动态抽象生成的前置条件

Dynamic Abstract Generation uses the Wire constraint group that is specified in the Wire Editing section of the Layout Editor options form.

动态抽象生成使用版图编辑器选项窗口中 Wire Editing 部分指定的 Wire 约束组（constraint group）。

The prerequisites for Dynamic Abstract Generation are as follows:

动态抽象生成的前置条件如下：

  • Valid vias and valid layers must be defined in the specified constraint group. If valid vias and valid layers are not present in the constraint group, a warning message is displayed in the CIW stating that the required information be added in the technology file.
  • 指定的约束组中必须定义有效的 via 和有效的层（layer）。如果约束组中没有有效 via 和有效层，CIW 会显示警告信息，提示在技术文件中补充所需信息。
  • The minSpacing and minWidth layer rules must be present in the technology file. During Dynamic Abstract Generation, the constraint groups are searched for layer rules in the following order:
    • Wire (user-defined) constraint group
    • LefDefaultRouteSpec constraint group by type
    • LefDefaultRouteSpec constraint group by name
    • Foundry constraint group

    For example, if the minSpacing value for metal3 is required, the minSpacing value is first searched for in the Wire constraint group. If the minSpacing value is found in the Wire constraint group, it is used. If the minSpacing value is not found in the Wire constraint group, the minSpacing value is searched for in the LefDefaultRouteSpec constraint group first by type and then by name. If the minSpacing value is not found in the LefDefaultRouteSpec constraint group too, the Foundry constraint group is searched for the minSpacing value.
  • 技术文件中必须包含 minSpacing 和 minWidth 层规则。在动态抽象生成过程中，系统会按以下顺序在约束组中查找层规则：
    • Wire（用户定义）约束组
    • LefDefaultRouteSpec（按类型）约束组
    • LefDefaultRouteSpec（按名称）约束组
    • Foundry 约束组

    例如，如果需要 metal3 的 minSpacing 值，系统首先在 Wire 约束组中查找。如果在 Wire 中找到，就使用该值。若在 Wire 中未找到，则会先按类型、再按名称在 LefDefaultRouteSpec 中查找。如果在 LefDefaultRouteSpec 中也未找到，则会在 Foundry 约束组中查找该 minSpacing 值。
  • Net and pin technology purpose must be present in the technology file. During Dynamic Abstract Generation, the net and pin purpose is used for net extraction and pin creation. If the net and pin purpose is not present in the technology file, Dynamic Abstract Generation adds the layer purpose pair information in the technology file, provided the write permission is available for the technology file.
  • 技术文件中必须存在 net 和 pin 的技术用途（purpose）定义。在动态抽象生成过程中，net 和 pin 的 purpose 用于网络抽取和引脚创建。如果技术文件中没有这些 purpose，在技术文件有写权限的前提下，动态抽象生成会向技术文件添加 layer-purpose pair 信息。
  • If an alternate foundry constraint group (AFCG) is defined in the .cdsenv file, Dynamic Abstract Generator replaces the foundry constraint group and uses the specified AFCG instead.
    You can specify an AFCG by setting the following environment variable in your .cdsenv file:
  • 如果在 .cdsenv 文件中定义了 alternate foundry 约束组（AFCG），动态抽象生成器（Dynamic Abstract Generator）会用指定的 AFCG 替换 foundry 约束组。
    可以通过在 .cdsenv 文件中设置以下环境变量来指定 AFCG：
 cdba.layout AlternateFoundryCG string "AFCG_name"
