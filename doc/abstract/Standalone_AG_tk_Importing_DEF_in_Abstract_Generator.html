Importing DEF in Abstract Generator

在 Abstract Generator 中导入 DEF

A DEF file contains the design-specific information of a circuit and is a representation of the design at any point during the layout process. The DEF file is in ASCII format. DEF conveys logical design data to and physical design data from P&R tools. Logical design data can include internal connectivity (represented by a net list), grouping information, timing parameters and physical constraints. Physical data includes placement locations and orientations, routing geometry data, and logical design changes for backannotation.

DEF 文件包含电路的设计专用信息，用于表示版图流程中任意阶段的设计状态。DEF 文件采用 ASCII 格式。DEF 将逻辑设计数据传递给 P&R 工具，并从 P&R 工具带回物理设计数据。逻辑设计数据可包括内部连通性（以 net list 表示）、分组信息、时序参数以及物理约束。物理数据包括放置位置与方向、布线几何数据，以及用于 backannotation 的逻辑设计变更。

  1. Choose File – Import – DEF. It displays the Import DEF form.
    The File – Import – DEF command imports a net list in DEF format and updates the design with the information.
  2. The DEF specifies the DEF files to import. You can type in the name manually or Browse for existing files with the.def extension in the current directory.
  3. In Default Bin, select the bin to which DEF data is to be imported.
    Cells will be placed in the Default Bin only if they conform to the following criteria:
    • There is a valid layout view.
    • The cell is not a via.
    • The cell is not a site.

    If any of this criteria is not met, the cells will be placed in the Ignore bin.
  4. Click OK.
  1. 选择 File – Import – DEF，将显示 Import DEF 表单。
    File – Import – DEF 命令会导入 DEF 格式的 net list，并用其中的信息更新设计。
  2. DEF 字段用于指定要导入的 DEF 文件。你可以手动输入文件名，或点击 Browse 在当前目录中选择扩展名为 .def 的现有文件。
  3. 在 Default Bin 中，选择要导入 DEF 数据的目标 bin。
    只有满足以下条件的 cell 才会被放入 Default Bin：
    • 存在有效的 layout view。
    • 该 cell 不是 via。
    • 该 cell 不是 site。

    如果不满足其中任一条件，该 cell 将被放入 Ignore bin。
  4. 点击 OK。
