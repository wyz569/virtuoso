Mark/Unmark Pcells for Abstraction Form

标记/取消标记用于抽象的 Pcell 表单

Use the Mark/Unmark Pcells for Abstraction form form to mark or unmark Pcells for abstraction.

使用 Mark/Unmark Pcells for Abstraction 表单可对 Pcell 进行抽象处理的标记或取消标记。

Field
字段 		Description
说明

Mark
标记

Marks the Pcells for abstraction.This is also the default option.

将 Pcell 标记为参与抽象处理。这也是默认选项。

Unmark
取消标记

Unmarks a Pcell for abstraction. As a result, the Pcell is ignored for the abstraction process.

取消某个 Pcell 的抽象标记。结果是该 Pcell 会在抽象处理流程中被忽略。

All Pcells
所有 Pcell

Abstracts all Pcells in the layout window.

对版图窗口中的所有 Pcell 生成抽象。

Selected Pcells
所选 Pcell

Abstracts the selected Pcells in the layout window.

对版图窗口中选中的 Pcell 生成抽象。
