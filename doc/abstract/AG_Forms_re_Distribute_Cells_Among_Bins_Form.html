Distribute Cells Among Bins Form
在 Bin 之间分配单元表单

The Distribute Cells Among Bins form lets you distribute cells among the system and user bins according to cell height, name or type.

Distribute Cells Among Bins form 允许你根据单元高度、名称或类型，将单元分配到 system bins 与 user bins。

Tab
选项卡 		Description
说明

Method

Method（方法）

This section allows you to specify the criteria you want to use.

该区域用于指定你要使用的分配条件。

Height

Height（高度）

Lets you specify a series of height ranges in μ, and the bins to which cells falling within a particular range are to be moved. To ensure that no cells are missed, only the lower bound of each range is editable. When you change the lower bound of one range, the upper bound of the next range down is adjusted automatically.

用于以 μ 为单位指定一系列高度范围，以及将落入某个范围的单元移动到的目标 bin。为确保不遗漏任何单元，每个范围只有下限可编辑；当你修改某个范围的下限时，下一个更低范围的上限会自动调整。

Name

Name（名称）

Lets you specify strings of characters and target bins for cell names containing those strings. For example, the settings shown above would move all the cells with names that include the string block to the Block bin, those including the string io to the IO bin, and so on.

用于为包含特定字符串的 cell 名称指定目标 bin。例如，上述设置会将名称中包含字符串 block 的所有单元移动到 Block bin，将包含字符串 io 的单元移动到 IO bin，依此类推。

Any cells not covered by specific criteria fall into the “other” category and are moved to the bin specified.

未被任何特定条件覆盖的单元会归入 “other” 类别，并移动到所指定的 bin。

Type

Type（类型）

Lets you distribute the cells to other system and user bins. The Type method distribution is based on the CellType attribute of a layout cell on OpenAccess.

用于将单元分配到其他 system bins 与 user bins。Type 方法基于 OpenAccess 上布局单元的 CellType 属性进行分配。

The first column represents the CellType attribute. By default, the CellType attributes in the first column are mapped to the corresponding system bins in the second column. The choices in the second column corresponding to a specific type are restricted to the user-defined and system bins of the same type. For example, if myBin is a user-defined bin of the type Block, myBin would be available for selection with the Block system bin in the second column. For cellviews with an unknown CellType (Other), all system and user-defined bins come up as options in the Ignore cyclic list.

第一列表示 CellType 属性。默认情况下，第一列的 CellType 会映射到第二列中对应的 system bin。对于某一特定类型，第二列可选项仅限于同类型的 user-defined bins 与 system bins。例如，如果 myBin 是类型为 Block 的 user-defined bin，那么在第二列中与 Block system bin 对应的选项里会提供 myBin 以供选择。对于 CellType 未知（Other）的 cellview，所有 system bins 与 user-defined bins 都会在 Ignore 循环列表中作为可选项出现。

Cells

Cells（单元）

This section allows you to specify whether you want to distribute all or selected cells when you open the form.

该区域用于指定打开表单时要分配全部单元还是仅分配所选单元。

All

All（全部）

Distributes all the cells displayed in the Cell pane.

分配 Cell 窗格中显示的所有单元。

Selected

Selected（已选择）

Distributes the set of selected cells displayed in the Cell pane.

分配 Cell 窗格中显示的已选择单元集合。
