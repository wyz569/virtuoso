Recording Commands and Events in Abstract Generator

在 Abstract Generator 中记录命令与事件

Every operation you perform during a session is recorded in a.record file. This allows you to rerun any session in batch mode and create user-defined macros with a minimum of manual intervention. Use the Record form to change the name of the record file, change the way the file is updated, or switch off recording altogether. The Record form controls the behavior of the record file, abstract.record.

会话期间你执行的每个操作都会被记录到一个 .record 文件中。这样你就可以在批处理模式下重放任意会话，并以最少的手工干预创建用户自定义宏。你可以使用 Record 窗体更改记录文件名、更改文件更新方式，或完全关闭记录功能。Record 窗体用于控制记录文件 abstract.record 的行为。

By default, abstract.record is the name of the record file. If a file with that name already exists, the existing file is renamed to abstract.record.n where n is equal to 1, and the new record file is named abstract.record.

默认情况下，记录文件名为 abstract.record。如果同名文件已存在，则现有文件会被重命名为 abstract.record.n（其中 n 从 1 开始），新的记录文件仍命名为 abstract.record。

If the name of the record file is not changed in subsequent sessions, the abstract.record file is renamed to abstract.record.(n+1) to maintain the older versions of the record file. Therefore, the greater the numeric value in the record file name, the recent (latest) that file is.

如果在后续会话中没有更改记录文件名，为了保留旧版本记录文件，abstract.record 会被重命名为 abstract.record.(n+1)。因此，记录文件名后缀数字越大，表示该文件越新（越接近最新）。

For example, if the file name is not changed in three successive sessions, the following record files are created:

例如，如果连续三次会话都没有更改文件名，将会生成以下记录文件：

  • abstract.record (Current record file)
  • abstract.record.2 (Next oldest)
  • abstract.record.1 (Oldest)
  • abstract.record（当前记录文件）
  • abstract.record.2（次新）
  • abstract.record.1（最旧）

Therefore, the abstract.record file is always the current record file. The other files with a numeric suffix are backups of previous record files.

因此，abstract.record 始终是当前记录文件；其他带数字后缀的文件则是先前记录文件的备份。

  1. Choose File – Record to start this command. This displays the Record form.
    选择 File – Record 启动该命令，系统会显示 Record 窗体。
  2. In Record File, specify the name of the record file. Use the Browse function to help you locate an existing file or change the current directory. If you do not change the name of the record file, it will be overwritten during the next Abstract Generator session.
    在 Record File 中指定记录文件名。可使用 Browse 帮助定位现有文件或更改当前目录。如果不更改记录文件名，它会在下一次 Abstract Generator 会话中被覆盖。
  3. Use the Mode pull-down list to select whether the commands of this session should overwrite or be appended to the record file or switch off the record function.
    使用 Mode 下拉列表选择：将本次会话的命令覆盖写入记录文件、追加到记录文件，或关闭记录功能。
The.record file does not acknowledge the selection of File – Exit.
.record 文件不会记录 File – Exit 的选择操作。
