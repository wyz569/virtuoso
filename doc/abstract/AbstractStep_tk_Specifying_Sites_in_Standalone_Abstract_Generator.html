Specifying Sites in Standalone Abstract Generator
在独立 Abstract Generator 中指定 Sites

Sites tell the placer where it can place cells. All cells located in a particular bin share a common set of properties: symmetry, class (for example, pad or core), width, and height. These properties are used by the placer to assist in the placement process.
Site 用于告知放置工具（placer）可在何处放置 cell。位于同一 bin 的所有 cell 共享一组共同属性：对称性、类别（例如 pad 或 core）、宽度与高度。放置工具会使用这些属性来辅助放置过程。

These cell properties are defined in a site object, and all cells within the same bin are associated with the same site. The site itself has a name, and the cells in the LEF file contain a site name field that holds the name of the associated site. You can create sites for the Core, IO, Corner bins.
这些 cell 属性定义在 site 对象中，同一 bin 内的所有 cell 都关联到同一个 site。Site 本身有名称，LEF 文件中的 cell 包含 site name 字段，用于保存关联 site 的名称。你可以为 Core、IO、Corner bin 创建 site。

In addition to the site names defined in the technology file, for CORE cells, the <AUTO> option is available in the Site Name cyclic field.
除了技术文件中定义的 site 名称外，对于 CORE cell，Site Name 循环字段还提供 <AUTO> 选项。

In addition to the site names defined in the technology file, for IO/Corner cells, the <AUTO> and <NONE> options available in the Site Name cyclic field.
除了技术文件中定义的 site 名称外，对于 IO/Corner cell，Site Name 循环字段还提供 <AUTO> 与 <NONE> 选项。

Behavior of the <AUTO> option:
<AUTO> 选项的行为：

  • If the layout has an existing site definition, then no default site is created. The site definition from the layout is retained in the final abstract view and is dumped in the LEF file.
    如果 layout 中已存在 site 定义，则不会创建默认 site。来自 layout 的 site 定义会保留在最终的 abstract 视图中，并写入 LEF 文件。
  • If the layout does not have any site definition, a new default site definition is created and is dumped in the LEF file.
    如果 layout 中没有任何 site 定义，则会创建新的默认 site 定义，并写入 LEF 文件。

Behavior of the <NONE> option:
<NONE> 选项的行为：

  • Any existing site definition is removed from the abstract view. So, no site definition is dumped in the LEF file.
    任何已有的 site 定义都会从 abstract 视图中移除，因此 LEF 文件中不会写入 site 定义。
  • If the layout does not have any site definition, then no new site definition is created. So, no site definition is dumped in the LEF file.
    如果 layout 中没有任何 site 定义，则不会创建新的 site 定义，因此 LEF 文件中不会写入 site 定义。

The <NONE> option is not available for CORE cells because CORE cells must have a site definition in LEF file.
由于 CORE cell 在 LEF 文件中必须具有 site 定义，因此 CORE cell 不提供 <NONE> 选项。

To specify sites in the Standalone Abstract Generator:
要在独立 Abstract Generator 中指定 sites：

  1. Choose Flow – Abstract, then click the Site tab in the Running step Abstract form.
    选择 Flow – Abstract，然后在 Running step Abstract 窗体中单击 Site 选项卡。
  2. From Site name, select a site name defined in the technology library from the available list to be applied to all cells in the current bin.
    在 Site name 中，从可用列表里选择技术库中定义的 site 名称，并将其应用于当前 bin 的所有 cell。
  3. In Define new site name, specify the name of a new site to be used by all cells in the current bin.
    在 Define new site name 中，指定一个新 site 的名称，使其被当前 bin 的所有 cell 使用。
  4. Use Calculate SITE pattern for Gate-array Cells to derive site patterns from the layout of gate-array standard cells. This option works exclusive of the single site creation fields on the Site tab.
    使用 Calculate SITE pattern for Gate-array Cells 从门阵列（gate-array）标准单元的 layout 推导 site pattern。该选项与 Site 选项卡上的单一 site 创建字段互斥。
  5. Specify the sub-cellview name in the Sub-Cellview column.
    在 Sub-Cellview 列中指定 sub-cellview 的名称。
  6. In the site column, the drop-down list displays the already existing sites. Select one from the list to map the selected sub-cellview.
    在 site 列中，下拉列表会显示已存在的 sites。从列表中选择一个 site 以映射所选 sub-cellview。
  7. Click Add to create the mappings. The Add button becomes active when you select the Calculate SITE pattern for Gate Array Cells option.
    单击 Add 创建映射。当你选择 Calculate SITE pattern for Gate Array Cells 选项后，Add 按钮将变为可用。

If a gate-array sub-cellview is itself associated with a site pattern, Abstract Generator preserves the pattern and exports it to LEF.
如果某个 gate-array sub-cellview 本身已关联了 site pattern，Abstract Generator 会保留该 pattern 并将其导出到 LEF。
