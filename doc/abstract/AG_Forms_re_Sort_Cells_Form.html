Sort Cells Form

单元排序表单

Use the Sort Cells form to sort the selected cells according to a variety of sorting criteria. The specified criteria are applied only to the selected cells displayed in the Cell pane and not to the overall library.

使用 Sort Cells 表单可按多种排序条件对所选单元进行排序。指定的条件仅应用于 Cell 窗格中显示的所选单元，而不影响整个库。

Field
字段 		Description
说明

Method

方法

Selects criterion for sorting from None, Name, Height, Status, or Selection.

从 None、Name、Height、Status 或 Selection 中选择排序条件。

  • Name sorts the selected cell list alphabetically by cell name.
    Name 按单元名称的字母顺序对所选单元列表排序。
  • Height sorts the selected cell list according to the heights of the cells in the specified View.
    Height 按指定 View 中单元的高度对所选单元列表排序。
  • Status sorts the selected cells according to the status of the View specified, listing cells in a sequence: unknown, warning, error, and invalid.
    Status 按指定 View 的状态对所选单元排序，单元按以下顺序列出：unknown、warning、error、invalid。
  • Selection moves all the selected cells to the top of the cell table.
    Selection 将所有已选单元移动到单元表格顶部。

View

视图

Lets you select a view for sorting. Select from Layout, Logical, Pins, Extract, or Abstract. The Height and Status methods consider only the view specified here. Cells that do not have the specified view are not sorted.

用于选择用于排序的 view。可从 Layout、Logical、Pins、Extract 或 Abstract 中选择。Height 与 Status 方法仅考虑此处指定的 view。不包含指定 view 的单元不会被排序。

Order

顺序

Lets you select an order of sorting. Select from Ascending or Descending.

用于选择排序顺序。可选择 Ascending 或 Descending。
