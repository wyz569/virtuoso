Abstracting Pcells

对 Pcell 进行抽象

To generate an abstract of a Pcell in the layout window:

要在版图窗口中为 Pcell 生成抽象：

  1. Choose Tools – Dynamic Abstract Generation For Pcells – Abstract Pcells.
    The Abstract Pcells form is displayed as shown in the figure below. When you point to an option in the Abstract Pcells form, an info balloon is displayed that describes the purpose of the option.
  2. 选择 Tools – Dynamic Abstract Generation For Pcells – Abstract Pcells。
    系统会显示 Abstract Pcells 窗口，如下图所示。将鼠标指向 Abstract Pcells 窗口中的某个选项时，会显示信息气泡来说明该选项的用途。
  3. In the Selection section, choose All Pcells to create abstracts for all the Pcells in the design. If you do not want to create the abstracts for all the Pcells, you can select the required Pcells in the layout canvas or from the Navigator assistant and ensure that the Selected Pcells option is selected. After you have run the command, you can select additional Pcells for abstraction, if required, and run the command again.
    The abstracts are created for all Pcells that are selected, except the ones that are unmarked for abstraction.
  4. 在 Selection 部分，选择 All Pcells 可为设计中的所有 Pcell 创建抽象。如果不希望为所有 Pcell 创建抽象，可以在 layout canvas 或 Navigator assistant 中选中所需的 Pcell，并确保选中 Selected Pcells 选项。运行命令后，如有需要还可以选择更多 Pcell 再次运行该命令。
    系统会为所有被选中的 Pcell 创建抽象，但会排除那些被取消标记为“需要抽象”的 Pcell。
  5. Check whether the abstracts were created successfully using one of the following methods:
    • View the blockages created at level-1in the layout canvas, as shown in the figure below.
    • View the status icons associated with the various Pcells in the Navigator assistant.
  6. 可使用以下任一方式检查抽象是否成功创建：
    • 在 layout canvas 中查看 level-1 创建的阻挡（blockage），如下图所示。
    • 在 Navigator assistant 中查看与各个 Pcell 关联的状态图标。
  7. In Options – Blockages section, you can specify the settings for blockage generation and for loading or saving an options file.
  8. 在 Options – Blockages 部分，你可以指定阻挡生成设置，以及加载或保存选项文件的设置。
  9. Use Cover Blockage Layers to specify layers and choose Detailed Blockage Layers to specify a layer-geometry specification.
  10. 使用 Cover Blockage Layers 来指定层，使用 Detailed Blockage Layers 来指定“层-几何”规格。
  11. Select Load/Save Options File to load or save the options file. You can use the following methods to load and save an options file:
    • Save the abstraction rules specified in the Abstract Pcells form to an options file.
      • Click Save to save the abstraction rules to an options file.
      • Specify the name of the options file to which you want to save the abstraction rules in the Options File Name field. You can also load an existing options file, edit it, and save the changes.
    • Load the various rules contained in an options file to the Abstract Pcells form. To load the abstraction rules contained in an options file, select the required options file and click Load.
  12. 选择 Load/Save Options File 可加载或保存选项文件。你可以使用以下方式来加载与保存选项文件：
    • 将 Abstract Pcells 窗口中指定的抽象规则保存到选项文件。
      • 点击 Save 将抽象规则保存到选项文件。
      • 在 Options File Name 字段中指定要保存抽象规则的选项文件名。也可以加载已有选项文件，编辑后再保存更改。
    • 将选项文件中包含的各类规则加载到 Abstract Pcells 窗口。要加载选项文件中的抽象规则，选择所需选项文件并点击 Load。
