Product Version IC23.1, November 2023

Abstract Generation Use Model

抽象生成使用模型

Abstract Generator generates LEF abstracts for cells in cell libraries. A cell library typically consists of standard cells but can also include IO and corner cells and some small custom blocks. The individual components of the library are described in an appropriate layout format, such as GDSII or LEF.

抽象生成器为单元库中的单元生成 LEF 抽象。单元库通常由标准单元组成，也可包含 IO 与角单元以及一些小型自定义模块。库的各个组件以适当的版图格式描述，例如 GDSII 或 LEF。

Abstract Generator lets you import layout information and create abstracts for some or all of the cells in the library. You can then reference any of the library cells in your design, safe in the knowledge that a suitable abstract exists for that cell. After generating abstracts for library cells, you should not have to return to the tool unless the library is revised either in response to some change in the fabrication process or through the addition of new cells or modification of the existing ones.

抽象生成器允许您导入版图信息，并为库中的部分或全部单元创建抽象。随后，您可以在设计中引用任何库单元，并确信该单元已有合适的抽象。为库单元生成抽象后，除非库因制造工艺变化或新增单元、修改既有单元而被修订，否则通常无需再回到该工具。

Abstract Generator satisfies the requirements of library designers and production engineers by presenting an uncluttered flow through the library development process.

抽象生成器通过在库开发过程中提供简洁的流程，满足库设计人员与生产工程师的需求。

The more experienced user enjoys maximum flexibility in entering cell information, partitioning cells into exclusive sets, fine tuning option settings, and iterating through the abstract generation process. The tool also provides reliable support for moving backward in the flow and clearing feedback on potential and real problems with the abstracts generated.

更有经验的用户可在输入单元信息、将单元划分为互斥集合、微调选项设置以及迭代抽象生成过程中获得最大灵活性。该工具也可靠地支持在流程中回退，并清除生成抽象时可能出现的潜在与实际问题的反馈。

The less experienced designer is provided with a simple flow through the essential steps required to update a library with predefined settings. The more flexible and user-friendly interface, that is, the integrated Abstract Generator, which can be launched in the Virtuoso Studio design environment is also available at the disposal of the novice users.

经验较少的设计人员可通过带有预定义设置的简单流程完成更新库所需的关键步骤。更灵活且更易用的界面——即可在 Virtuoso Studio 设计环境中启动的集成式抽象生成器——也可供新手用户使用。
