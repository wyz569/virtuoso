Specifying Antenna Options for Dynamic Abstraction

指定动态抽象的天线选项

You can specify antenna options for dynamic Abstraction using the Save Dynamic Abstract Generation Options form. By using the options on the Antenna tab, you can create process antenna data for Pcells. By default, all the check boxes on this tab are deselected.

你可以使用 Save Dynamic Abstract Generation Options 窗口为动态抽象指定天线选项。通过 Antenna 选项卡中的选项，你可以为 Pcell 创建工艺天线数据。默认情况下，该选项卡中的所有复选框均未勾选。

  1. In the Antenna Calculation section, use the following options to computes the process antenna data for a given layer.
    • Hierarchical Antenna
    • Antenna for Input Pin
    • Antenna for Output Pin
    • Antenna for In-Out Pin
    • Extract Metal Area
    • Extract Metal Side Area
  2. Select the Diffusion Layers check box to extract diffusion layers specified in the technology file.
  3. In the Antenna Layers field, specify the layers for which you want to calculate their process antenna data.
  4. In the Define Gate Area and Define Drain Area fields, specify the layer-geometry specification for defining the gate and drain geometry regions, respectively. An example that defines the gate area region is as follows:
    (poly and fiff)
    An example that defines the drain region area is as follows:
    (diff andnot poly)
  5. From the Define Oxide Number drop-down list, select the oxide model to be extracted for a particular diffusion layer. The list contains four oxide types: Oxide1, Oxide2, Oxide3, and Oxide4. You can apply a unique oxide model for up to four diffusion layers.
  6. Click Close after setting the required fields.
  1. 在 Antenna Calculation 部分，使用以下选项为指定层计算工艺天线数据。
    • Hierarchical Antenna（分层天线）
    • Antenna for Input Pin（输入 pin 天线）
    • Antenna for Output Pin（输出 pin 天线）
    • Antenna for In-Out Pin（输入/输出 pin 天线）
    • Extract Metal Area（提取金属面积）
    • Extract Metal Side Area（提取金属侧壁面积）
  2. 勾选 Diffusion Layers 复选框，以提取技术文件中指定的扩散层。
  3. 在 Antenna Layers 字段中，指定要计算其工艺天线数据的层。
  4. 在 Define Gate Area 与 Define Drain Area 字段中，分别指定用于定义栅极与漏极几何区域的 layer-geometry 规格。定义 gate area 区域的示例如下：
    (poly and fiff)
    定义 drain 区域的示例如下：
    (diff andnot poly)
  5. 在 Define Oxide Number 下拉列表中，为特定扩散层选择要提取的氧化层模型。该列表包含四种氧化层类型：Oxide1、Oxide2、Oxide3 和 Oxide4。最多可为四个扩散层分别应用不同的氧化层模型。
  6. 设置完成所需字段后点击 Close。
