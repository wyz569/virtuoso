Specifying Layers and Geometries for Extraction

指定用于抽取的层与几何图形

To extract geometries on signal or power nets or to calculate process antenna information, you need to provide information about them to Abstract Generator. The Extract step provides three different tab locations - Signal, Power, and Antenna - for you to provide these details.

要在 signal 或 power 网络上抽取几何图形，或计算工艺天线信息，你需要向 Abstract Generator 提供相关信息。Extract 步骤提供了三个选项卡位置：Signal、Power 和 Antenna，用于输入这些细节。

  1. Choose Flow – Extract. The Signal tab is the first tab in the Running step Extract form.
  2. Select the Extract signal nets option to direct Abstract Generator to run connectivity extraction for signal nets.
    Selecting the Extract signal nets option activates the Layer Assignment for Signal Extraction table.
  3. In the Layer Assignment for Signal Extraction table, specify the layers through which you want Abstract Generator to extract. You can also specify the geometry or shapes that should be present on a particular layer when signal net extraction is performed.
  4. In the Layer Assignment for Signal Extraction table, specify the Layer on which signal net extraction is to be performed, and set the Geometry Specification for the layers specified in this table.
  5. In the Connectivity column, you can specify the type of connectivity setting, Strong or Weak, for a particular layer. The connectivity setting is valid for a layer only if a geometry specification is provided for that layer.
  6. Use the Add, Edit, and Delete buttons and the G-Spec Builder Form in conjunction with the Operators to work with the Layer Assignment for Signal Extraction table.
  7. Use the Maximum depth, Maximum distance, and Minimum width fields for specifying the extraction limits.
  8. In the Create Must Join Pins If Required section, you can control what happens when the extractor finds two disjoint groups of shapes extracted for the same net.
    The Extract signal nets option should be selected in order to generate the must-join pins. If the Extract signal nets option is OFF, then the Create Must Join Pins If Required options do not have any effect.
  9. Use the Always option and the Only on terminals named field to create LEF must-join relationships between disjoint geometries extracted from separate starting pins on the same net.
  1. 选择 Flow – Extract。在 Running step 的 Extract 表单中，Signal 选项卡是第一个选项卡。
  2. 选择 Extract signal nets 选项，指示 Abstract Generator 对 signal nets 运行连通性抽取。选择该选项会激活 Layer Assignment for Signal Extraction 表格。
  3. 在 Layer Assignment for Signal Extraction 表格中，指定希望 Abstract Generator 进行抽取所经过的层。你还可以指定在进行 signal net 抽取时，某一层上应存在的几何图形或形状。
  4. 在该表格中，指定进行 signal net 抽取的 Layer，并为表中所列层设置 Geometry Specification。
  5. 在 Connectivity 列中，你可以为特定层指定连通性类型：Strong 或 Weak。只有当该层提供了几何规格（geometry specification）时，该连通性设置才对该层有效。
  6. 结合 Operators 使用 Add、Edit 与 Delete 按钮，以及 G-Spec Builder Form 来编辑 Layer Assignment for Signal Extraction 表格。
  7. 使用 Maximum depth、Maximum distance 和 Minimum width 字段来指定抽取限制。
  8. 在 Create Must Join Pins If Required 区域中，你可以控制当抽取器为同一网络找到两组不连通的抽取形状时的处理方式。要生成 must-join pins，必须选择 Extract signal nets 选项；如果 Extract signal nets 选项为 OFF，则 Create Must Join Pins If Required 的选项不会生效。
  9. 使用 Always 选项与 Only on terminals named 字段，在同一网络上从不同起始引脚抽取出的不连通几何之间创建 LEF must-join 关系。

You can face the following issue while using the Running Step Extract form and the following error message might be displayed.

在使用 Running Step Extract 表单时，你可能会遇到以下问题，并显示如下错误信息。

ABS-23005

Cell name: Terminal name has been ignored although it has the mustJoin attribute because it was not indicated in the Create Must Join Pins If Required section on the Signal page.

Cell name：Terminal name 虽然具有 mustJoin 属性，但由于未在 Signal 页面中的 Create Must Join Pins If Required 区域指明，因此已被忽略。

Troubleshooting: To ensure that must-join pins are created for terminals, select the Always option or include specific terminals in the Only on terminals named field.

故障排查：为确保为端子创建 must-join pins，请选择 Always 选项，或在 Only on terminals named 字段中包含特定端子。
