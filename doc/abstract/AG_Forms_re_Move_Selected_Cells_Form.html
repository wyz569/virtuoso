Move Selected Cells Form

移动所选单元表单

Use the Move Selected Cells form to moves one or more selected cells to a different bin.

使用 Move Selected Cells 表单可将一个或多个选中的单元移动到不同的 bin。

Field
字段 		Description
说明

To bin
目标 bin

Lets you choose the target bin and move the selected cells into the selected bin. The status for all the views remains unchanged.

用于选择目标 bin，并将所选单元移动到该 bin。所有视图的状态保持不变。
