Virtuoso Layout Flow

Virtuoso 版图流程

This flow facilitates a tight integration between Abstract Generator and Virtuoso Floorplanner, which bypasses the import and export LEF steps used in the LEF to OA flow.

该流程实现了抽象生成器与 Virtuoso Floorplanner 的紧密集成，从而绕过 LEF to OA 流程中使用的导入与导出 LEF 步骤。

In this flow, all layout data creation and abstract generation stay within the Virtuoso Studio design environment. There is no requirement for LEF. This part of the flow can be done by using Virtuoso Floorplanner or Abstract Generator. The DEF side of the flow requires a netlist and can only be done by using Virtuoso Floorplanner.

在此流程中，所有版图数据创建与抽象生成都在 Virtuoso Studio 设计环境内完成，无需 LEF。流程的这部分可使用 Virtuoso Floorplanner 或抽象生成器完成。流程的 DEF 侧需要网表，并且只能通过 Virtuoso Floorplanner 完成。

Virtuoso Floorplanner can invoke Abstract Generator to generate an abstract view for either a layout or a softLayout view.

Virtuoso Floorplanner 可调用抽象生成器，为 layout 或 softLayout 视图生成抽象视图。
