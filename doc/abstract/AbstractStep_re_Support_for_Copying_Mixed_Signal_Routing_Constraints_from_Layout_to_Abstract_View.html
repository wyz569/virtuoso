Virtuoso Abstract Generator User Guide
Product Version IC23.1, November 2023

Support for Copying Mixed Signal Routing Constraints from Layout to Abstract View
支持将混合信号布线约束从 Layout 复制到 Abstract 视图

In a layout design, you can create mixed signal routing constraints on a block using the Virtuoso Constraint Manager. When an abstract is created for a block from a layout design, the abstract view does not contain the constraint information of the block.

在布局设计中，你可以使用 Virtuoso Constraint Manager 为某个 block 创建混合信号布线约束。当从 layout 设计为 block 生成 abstract 时，abstract 视图默认不包含该 block 的约束信息。

Abstract Generator provides support for copying mixed signal routing constraints from the layout view to the abstract view. In this release, the following mixed signal routing constraints are supported.

Abstract Generator 支持将混合信号布线约束从 layout 视图复制到 abstract 视图。在此版本中，支持以下混合信号布线约束：

  • ciDiffPairType
  • ciShieldingType
  • ciNetBusType
  • ciSymmetryType
  • ciProcessOverrideType
  • ciMatchedLengthType

You can copy the option signal routing constraints from the layout view to the abstract view, either while a new abstract is being generated or to an existing abstract, as explained below:

你可以将可选的混合信号布线约束从 layout 视图复制到 abstract 视图：既可在生成新 abstract 时复制，也可复制到现有 abstract，如下所述：

  • Copying constraints to new abstracts during abstract generation
    在生成 abstract 过程中将约束复制到新 abstracts
    To copy mixed signal routing constraints to the new abstracts that are created, set the CopyMSRoutingConstraints option to TRUE. See CopyMSRoutingConstraint.
    要将混合信号布线约束复制到新建的 abstracts，请将 CopyMSRoutingConstraints 选项设置为 TRUE。参见 CopyMSRoutingConstraint。
    In addition, for a constraint to be copied to the abstract view, the following three conditions must be satisfied:
    此外，要将约束复制到 abstract 视图，还必须满足以下三个条件：
    • The routing constraints must be present in the top-level layout view
      布线约束必须存在于顶层 layout 视图中
    • The routing constraint must be present in a net that is part of the abstract
      布线约束必须位于属于该 abstract 的某条网络上
    • The routing constraint must have the Hierarchical Scope attribute set to above
      布线约束的 Hierarchical Scope 属性必须设置为 above

    Hierarchical scope is an attribute of a routing constraint that can have the following values: local, below, and above. The value ‘local’ is always set for a routing constraint.
    Hierarchical scope 是布线约束的一个属性，可取值为 local、below、above。对于布线约束，始终会设置 ‘local’ 这一值。
    By default, the value of the Hierarchical scope attribute is set to local. Therefore, ensure that you set it to above before you create the abstract from the layout.
    默认情况下，Hierarchical scope 属性值为 local。因此，在从 layout 创建 abstract 之前，请确保将其设置为 above。
  • Copying constraints to existing abstracts without regenerating the abstracts
    无需重新生成即可将约束复制到现有 abstracts
    You can add mixed signal routing constraints to existing abstracts in VLS XL and VLS GXL. To add constraints, open the existing abstract view in the Virtuoso Layout window and use one of the following methods:
    你可以在 VLS XL 与 VLS GXL 中为现有 abstracts 添加混合信号布线约束。要添加约束，请在 Virtuoso Layout 窗口中打开现有 abstract 视图，并使用以下方法之一：
    • Load the constraints from the specified connectivity source view by choosing Connectivity – Update – Layout Constraints.
      通过选择 Connectivity – Update – Layout Constraints，从指定的连通性源视图加载约束。
    • Copy the constraints from a layout view by using the Load Physical View command.
      使用 Load Physical View 命令从 layout 视图复制约束。
    • Add constraints to an existing abstract by using the Routing constraints available in the Constraint Creation list in the Constraint Manager.
      在 Constraint Manager 的 Constraint Creation 列表中，使用可用的 Routing constraints 将约束添加到现有 abstract。
