Troubleshoot Layer Spacing Rules Issues

层间距规则问题排查

If a layer has spacing rules that are defined in the spacingTables section of a constraint group, Abstract Generator proceeds depending on the layer definition in other sections of the technology file.

如果某层的间距规则定义在约束组的 spacingTables 章节中，Abstract Generator 会根据该层在技术文件其他章节中的定义情况来决定是否继续执行。

  • If the layer is also defined in the functions subsection of the layerRules section, it represents an ideal situation and Abstract Generator proceeds without issuing any messages.
    如果该层也在 layerRules 章节的 functions 子节中定义，这是理想情况，Abstract Generator 会继续执行且不会输出任何消息。
  • If the layer is not additionally defined in the functions subsection of the layerRules section, Abstract Generator stops further execution and issues the error message ABS-10021.
    如果该层未在 layerRules 章节的 functions 子节中额外定义，Abstract Generator 会停止后续执行并报错 ABS-10021。

ABS-10021
ABS-10021（层定义缺失）

Layer definition is missing from one or more of these sections in the technology file: techLayers, techLayerPurposePriorities, techDisplays; functions subsection in the layerRules section; or interconnect section of the LefDefaultRouteSpec constraint group. Use the Technology File Manager to define the layer in all the required sections in the technology file. Save and reload the file.

技术文件的以下一个或多个章节中缺少该层的定义：techLayers、techLayerPurposePriorities、techDisplays；layerRules 章节的 functions 子节；或 LefDefaultRouteSpec 约束组的 interconnect 章节。请使用 Technology File Manager 在技术文件所有必需章节中定义该层，然后保存并重新加载该文件。

ABS-10059
ABS-10059（派生层不受支持）

The layer layerName, defined in the spacingTables section of the foundry constraint group, is also defined in the techDerivedLayers section of the technology file. The abstract generator does not support derived layers and this layer will, therefore, be ignored. As a result, the abstracts generated will not have any shape on this layer.

在 foundry 约束组的 spacingTables 章节中定义的层 layerName，同时也在技术文件的 techDerivedLayers 章节中定义。abstract generator 不支持派生层（derived layers），因此会忽略该层。结果是生成的 abstracts 在该层上不会包含任何形状。
