G-Spec Builder Form

G-Spec 构建器表单

Use the G-Spec Builder form to build own geometry specifications (g-specs) using temporary layers. These temporary layers are then translated into the correct g-spec syntax.

使用 G-Spec Builder 表单可通过临时层构建自定义几何规格（g-spec）。这些临时层随后会被转换为正确的 g-spec 语法。

Field
字段 		Description
说明

Result
结果

Specifies the layer on which the resulting shapes from the Boolean operation will be placed.

指定布尔运算生成的结果图形应放置到的层。

You can do one of the following:

你可以执行以下任一操作：

  • Select a layer that exists in the technology file.
    选择技术文件中已存在的层。
  • Manually enter the name of a layer that exists in the technology file.
    手动输入技术文件中已存在的层名。
  • Manually enter the name of a temporary layer.
    手动输入临时层的名称。

Layer 1
层 1

Specifies the layer of the layer-purpose pair being used for defining the geometry specification.

指定用于定义几何规格的层/目的（layer-purpose pair）中的层。

You can do one of the following:

你可以执行以下任一操作：

  • Select a layer that exists in the technology file.
    选择技术文件中已存在的层。
  • Manually enter the name of a layer that exists in the technology file.
    手动输入技术文件中已存在的层名。
  • Manually enter the name of a temporary layer.
    手动输入临时层的名称。

Purpose 1
目的 1

Specifies an al field. As above, the layer or layer-purpose pair must be present in the technology file.

用于指定一个目的（purpose）的输入字段。与上面相同，层或层/目的对必须存在于技术文件中。

Operator
运算符

Selects an operator to use in the Boolean operation. The size operator accepts a float number rather than another layer-purpose pair as an argument. In this case, the layer field already defined in the technology file is editable.

选择要用于布尔运算的运算符。size 运算符的参数是浮点数，而不是另一个层/目的对。在这种情况下，技术文件中已定义的层字段是可编辑的。

Layer 2
层 2

Specifies the layer of the second layer-purpose pair being used for defining the geometry specification.

指定用于定义几何规格的第二个层/目的对中的层。

You can do one of the following:

你可以执行以下任一操作：

  • Select a layer that exists in the technology file.
    选择技术文件中已存在的层。
  • Manually enter the name of a layer that exists in the technology file.
    手动输入技术文件中已存在的层名。
  • Manually enter the name of a temporary layer.
    手动输入临时层的名称。

Purpose 2
目的 2

Specifies an al field where you can specify the name of a purpose. The layer or the layer-purpose pair must be present in the technology file.

用于指定目的（purpose）名称的输入字段。层或层/目的对必须存在于技术文件中。
