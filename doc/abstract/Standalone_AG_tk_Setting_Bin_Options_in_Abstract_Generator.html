Setting Bin Options in Abstract Generator

设置 Bin 选项

The Bin Options form allows you to view and change the options associated with system and user bins. These options control the way in which Abstract Generator processes the cells contained in any given bin.

Bin Options 窗体允许你查看与修改系统 bin 和用户 bin 的相关选项。这些选项控制 Abstract Generator 处理任意 bin 中 cell 的方式。

  1. Choose Bins – Options to open the Bin Options form.
    选择 Bins – Options 打开 Bin Options 窗体。
    When you run flow steps on selected cells, you see a modified version of the Bin Options form, which lets you view and change options relevant to the steps about to be run.
    当你对已选 cell 运行流程步骤时，会看到 Bin Options 窗体的一个修改版本，可用于查看与更改即将运行步骤相关的选项。
  2. In the Bin Selector section, use the option settings are applied to the bin specified in the panel on the left of the form.
    在 Bin Selector 区域中，选项设置会应用到窗体左侧面板所指定的 bin。
    If there is a bin selected when you open the form, it will be selected here with the option settings for that bin displayed. If there are multiple bins selected, the first bin in the list is selected. You can view and change the options associated with any other bin by clicking the button next to the bin name.
    如果打开窗体时已有选中的 bin，这里会选中该 bin 并显示其选项设置。如果选中了多个 bin，则会选择列表中的第一个 bin。点击 bin 名称旁的按钮即可查看和更改其他 bin 的相关选项。
  3. In the Step Selector section, you can access the options associated with each step in the top left of the Bins Options form. The abstract generation flow is split into four steps: Pins, Extract, and Abstract.
    在 Step Selector 区域中，你可以在 Bin Options 窗体左上方访问每个步骤的选项。Abstract 生成流程被拆分为多个步骤（如 Pins、Extract、Abstract）。
    When you open the Bin Options form, the default selection is Pins. Use the buttons to view and modify options associated with the other steps.
    打开 Bin Options 窗体时默认选中 Pins。你可以使用按钮查看并修改其他步骤对应的选项。
  4. Use the options associated with each flow step are further grouped into logical categories, accessed by clicking the appropriate tab at the top.
    每个流程步骤对应的选项会进一步按逻辑类别分组，可通过点击顶部相应标签页访问。
    When setting options, consider the following rules:
    设置选项时，请注意以下规则：
    • Measurements: All options that take measurements, for example for coordinates or distances, are specified in μ.
      Measurements：所有涉及量值（例如坐标或距离）的选项均以 μ 为单位指定。
    • Layers: Where an option takes a layer name, the name supplied must be defined in the technology file; otherwise, the entry is rejected and an error is generated when you try to move from the field in question.
      Layers：当选项需要 layer name 时，所提供名称必须在 technology file 中定义；否则该输入会被拒绝，并在你离开该字段时产生错误。
    • Purpose: Only purposes defined in the technology file are valid.
      Purpose：仅 technology file 中定义的 purpose 才是有效的。
  5. Select Copy From Bin to copy option settings from another bin to the selected bin. This is useful when creating a new user bin; you can selectively copy bin specific options only while copying options from one bin to another.
    选择 Copy From Bin 可将另一个 bin 的选项设置复制到当前选中的 bin。这在创建新的用户 bin 时很有用：你可以在复制时仅选择性复制与 bin 相关的选项。
    • Click the Copy From Bin button to open the Copy Bin Options form.
      点击 Copy From Bin 按钮打开 Copy Bin Options 窗体。
    • In the From field, select the bin whose options you want to copy and click OK. For example, the settings for the Core bin could be copied to UserBin.
      在 From 字段中选择要复制其选项的 bin，并点击 OK。例如，可以将 Core bin 的设置复制到 UserBin。
    • The current bin is entered automatically in the To field.
      To 字段会自动填入当前 bin。

    This function overwrites all the current option settings for the target bin.
    该功能会覆盖目标 bin 当前的所有选项设置。
  6. Click OK.
    点击 OK。
