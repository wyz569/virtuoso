Processing Antenna Information in Standalone Abstract Generator

在独立版 Abstract Generator 中处理天线信息

To access the Antenna tab in the Running step Extract form:

要在 Running step Extract 表单中访问 Antenna 选项卡：

  1. Choose Flow – Extract and click the Antenna tab in the Running step Extract form.
    选择 Flow – Extract，并在 Running step Extract 表单中单击 Antenna 选项卡。
    The options on this tab let you create process antenna information for custom blocks and standard cells. By default, all the options on this tab are off.
    此选项卡上的选项可用于为自定义 block 与标准单元创建工艺天线信息。默认情况下，该选项卡上的所有选项均处于关闭状态。
  2. Choose one of the following options on the Antenna tab for calculating process antenna data:
    在 Antenna 选项卡上选择以下选项之一，以计算工艺天线数据：
    • Calculate hierarchical antenna
      计算分层天线
    • Calculate input pin antenna
      计算输入引脚天线
    • Calculate output pin antenna
      计算输出引脚天线
    • Calculate inout pin antenna
      计算双向引脚天线
    • Calculate antenna metal area
      计算天线金属面积
    • Calculate antenna metal side area
      计算天线金属侧面积
  3. Select Layer Assignment for Antenna Regions to assign layers to antenna regions for identifying the gate and drain regions and to enable antenna calculation. This table is enabled when at least one of the calculate antenna options is active.
    选择 Layer Assignment for Antenna Regions，为天线区域分配层，用于识别栅极与漏极区域并启用天线计算。该表在至少启用一个“计算天线”选项时可用。
  4. Use the Add, Edit, and Delete buttons and the G-Spec Builder Form in conjunction with the operators to work with the Layer Assignment for Antenna Regions table.
    结合运算符使用 Add、Edit、Delete 按钮以及 G-Spec Builder Form，以操作 Layer Assignment for Antenna Regions 表。
  5. Select Use different layer assignments for antenna calculations only to set layer assignments for antenna extraction different from those set for signal net extraction set on the Signal and Antenna tabs.
    选择 Use different layer assignments for antenna calculations only，可将天线提取的层分配设置为与 Signal 与 Antenna 选项卡上用于信号网络提取的层分配不同。
    This option activates the Layer Assignment for Antenna Extraction table and consequently over-rides any Layer Assignment for Signal Extraction option settings.
    The columns of this table are described below.
    • Specify the Layer for which you want to extract antenna data.
    • Enter a Geometry Specification for each layer through which you want to extract antenna data.

    该选项会启用 Layer Assignment for Antenna Extraction 表，从而覆盖任何“Layer Assignment for Signal Extraction”的选项设置。表格列含义如下：
    - 指定要提取天线数据的 Layer。
    - 为希望进行天线数据提取的每一层输入 Geometry Specification。
  6. Use the Add, Edit, and Delete buttons and the G-Spec Builder Form in conjunction with the operators to work with the Layer Assignment for Antenna Extraction table.
    结合运算符使用 Add、Edit、Delete 按钮以及 G-Spec Builder Form，以操作 Layer Assignment for Antenna Extraction 表。
  7. Select Signal nets to be excluded from antenna calculation to specify the nets that should not be considered for antenna extraction and therefore, lets you avoid antenna calculations for the specified pins.
    选择 Signal nets to be excluded from antenna calculation，指定不应纳入天线提取的网络，从而避免对指定引脚进行天线计算。
