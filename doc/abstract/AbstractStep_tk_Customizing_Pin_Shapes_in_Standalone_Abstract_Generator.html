Customizing Pin Shapes in Standalone Abstract Generator

在独立 Abstract Generator 中自定义引脚形状

The options on the Adjust tab of the Running step Abstract for the selected cell(s) form control how pin shapes are adjusted during connectivity extraction for creating the final required pin shapes. These pin shapes are then fractured into rectangles. The options help you ensure that if a pin shape is reduced in any way, the discarded part of the pin is turned into a blockage, and the blockage is spaced sufficiently away from the reduced pin shape.

在“为所选单元运行步骤 Abstract”表单的 Adjust（调整）选项卡中，这些选项用于控制在连通性抽取过程中如何调整引脚形状，以生成最终所需的引脚形状。随后，这些引脚形状会被裂解为矩形。这些选项可帮助你确保：当引脚形状以任何方式被缩减时，被丢弃的部分会转换为阻挡（blockage），并且该阻挡会与缩减后的引脚形状保持足够的间距。

To customize the pin shapes in Standalone Abstract Generator:

要在独立 Abstract Generator 中自定义引脚形状：

  1. Choose Flow – Abstract. The Adjust tab is the first tab in the Running step Abstract for the selected cell(s) form.
    选择 Flow – Abstract。在“为所选单元运行步骤 Abstract”表单中，Adjust（调整）是第一个选项卡。
  2. In the Signal Nets section, you can control how pin shapes are adjusted during connectivity extraction to create the final required pin shapes for signal nets.
    在 Signal Nets（信号网络）区域中，你可以控制在连通性抽取过程中如何调整引脚形状，以生成信号网络最终所需的引脚形状。
    • Select Create boundary pins to adjust the pin shapes created during extraction to be square and on the cell boundary.
      选择 Create boundary pins，将抽取过程中创建的引脚形状调整为正方形并放置在单元边界上。
    • Use Boundary pin max distance to boundary to specify the maximum distance (in microns) of the signal net or power net geometries from the boundary so that they can be considered as boundary pins.
      使用 Boundary pin max distance to boundary 指定信号网或电源网几何图形到边界的最大距离（微米），以便将其视为边界引脚。
    • Select Signal geometry groups to control how signal net shapes are grouped into LEF PORTS.
      选择 Signal geometry groups 以控制如何将信号网络形状分组到 LEF PORTS 中。
  3. In the Power Nets section, you can control how pin shapes are adjusted during connectivity extraction to create the final required pin shapes for power nets.
    在 Power Nets（电源网络）区域中，你可以控制在连通性抽取过程中如何调整引脚形状，以生成电源网络最终所需的引脚形状。
    • Select Create boundary pins to adjust the pin shapes created during extraction to be square and on the cell boundary.
      选择 Create boundary pins 将抽取过程中创建的引脚形状调整为正方形并放置在单元边界上。
    • Use Boundary pin max distance to boundary to specify the maximum distance (in microns) of the signal net or power net geometries from the boundary so that they can be considered as boundary pins.
      使用 Boundary pin max distance to boundary 指定信号网或电源网几何图形到边界的最大距离（微米），以便将其视为边界引脚。
    • Select Create ring pins to create ring pins where any extreme shapes, that are close to the cell boundary existing in a power net are found to form a ring.
      选择 Create ring pins，当电源网络中靠近单元边界的极端形状可构成环形时，创建环形引脚。
    • Use Ring pin max distance to boundary to specify (in microns) the maximum distance within which the extracted power net geometry can be from the boundary in order for it to be considered as part of the ring, and therefore, be included in the abstract as pin geometry.
      使用 Ring pin max distance to boundary 指定（微米）抽取到的电源网络几何图形距离边界的最大距离；在该距离内的几何图形会被视为环形的一部分，并作为引脚几何包含到摘要中。
    • Select Follow ring pin to consider all pin shapes, including the ones that are not part of the ring, as pins in the final abstract.
      选择 Follow ring pin，将所有引脚形状（包括不属于环形的部分）都视为最终摘要中的引脚。
    • Select Power geometry groups to control how power shapes are grouped into LEF PORTS.
      选择 Power geometry groups 以控制如何将电源形状分组到 LEF PORTS 中。
    • Use Power rail widths, offsets and shape to specify the characteristics of the power and ground rails for the current bin.
      使用 Power rail widths、offsets and shape 指定当前 bin 的电源/地电源轨特性。
  4. In the CORE/BUMP Ports section, you can specify the following CLASS CORE-specific information to Abstract Generator.
    在 CORE/BUMP Ports 区域中，你可以向 Abstract Generator 指定以下与 CLASS CORE 相关的信息。
    • Use Cell edge facing core to specify the direction in which the CORE-facing edge is pointing, north, south, east, west, or a combination of any of the four core edges.
      使用 Cell edge facing core 指定面向 CORE 的边所指方向：north、south、east、west，或四条 core 边中任意组合。
    • Use Power/ground net to have CLASS CORE ports to specify the nets that should have CLASS CORE ports. This can be specified by entering a regular expression in the field.
      使用 Power/ground net to have CLASS CORE ports 指定应具有 CLASS CORE 端口的网络，可在该字段中输入正则表达式进行指定。
    • Select Allow multiple CLASS CORE ports to specify that two ports equidistant from the core-facing edge of a pad are both assigned the CLASS CORE statement in LEF.
      选择 Allow multiple CLASS CORE ports，使得距离 pad 面向 core 边等距的两个端口在 LEF 中都被赋予 CLASS CORE 声明。
    • Select Copy CLASS CORE ports to duplicate any geometry found to belong to a CLASS CORE port on the net (set by using the Power/ground net to have CLASS CORE ports option) in a non-CLASS CORE port to the exported abstract LEF.
      选择 Copy CLASS CORE ports，将网络中属于 CLASS CORE 端口的几何图形（由 Power/ground net to have CLASS CORE ports 选项设置）复制到一个非 CLASS CORE 端口中，并导出到摘要 LEF。
    • Select Create CLASS CORE ports only if pin meets cell boundary to specify that only the pins that either touch or cross the core-facing edge of the boundary become CLASS CORE ports in LEF.
      选择 Create CLASS CORE ports only if pin meets cell boundary，仅当引脚接触或穿过边界中面向 core 的边时，才会在 LEF 中成为 CLASS CORE 端口。
    • Select Create CLASS CORE ports if pin meets non-core facing edge to allow the pins that touch the non-core facing edge to become eligible to be included as CLASS CORE ports.
      选择 Create CLASS CORE ports if pin meets non-core facing edge，允许接触非 core 朝向边的引脚也具备作为 CLASS CORE 端口被包含的资格。
    • Select Create CLASS BUMP ports to consider power nets of cell type IO for creating the CLASS BUMP ports.
      选择 Create CLASS BUMP ports，对 IO 类型单元的电源网络创建 CLASS BUMP 端口。
  5. Click Run.
    点击 Run。
