Add User Bin Form
添加用户 Bin 表单

Use the Add User Bin form to add a new user bin to the list of existing bins.

使用 Add User Bin 表单，将新的用户 bin 添加到现有 bin 列表中。

Field
字段 		Description
说明

Enter bin name

输入 bin 名称

Lets you specify the name of the new bin. The bin name should contain any spaces.

用于指定新 bin 的名称。bin 名称中可以包含空格。

Choose bin type

选择 bin 类型

Lets you select a bin from the drop-down list. The bin type determines the default options settings for the new bin. Therefore, for example, if you create a new user bin of type Core, the user bin options will be identical to those currently set for the default Core bin.

用于从下拉列表中选择一个 bin。bin 类型决定新建 bin 的默认选项设置。因此，例如，如果创建类型为 Core 的新用户 bin，那么该用户 bin 的选项将与当前默认 Core bin 的设置完全一致。
