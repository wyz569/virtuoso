Distributing Cells into Bins in Abstract Generator

在 Abstract Generator 中将 Cell 分配到 Bin

Use the Distribute Cells Among Bins form to distribute cells among the system and user bins according to cell height, name, or type.

使用 Distribute Cells Among Bins 表单，可根据 cell 的高度、名称或类型，将 cell 分配到 system bin 与 user bin 中。

  1. Choose Cells – Distribute to open the Distribute Cells Among Bins form.
  2. The Method group options allow you to specify the criteria you want to use. Choose from Height, Name and Type.
  3. Selecting the Height method changes the lower part of the form to display the following:
    You can specify a series of height ranges in μ, and the bins to which cells falling within a particular range are to be moved. To ensure that no cells are missed, only the lower bound of each range is editable. When you change the lower bound of one range, the upper bound of the next range down is adjusted automatically.
  4. Selecting the Name method changes the lower part of the form to display the following:
    You can specify strings of characters and target bins for cell names containing those strings. For example, the settings shown above would move all the cells with names that include the string block to the Block bin, those including the string io to the IO bin, and so on. Any cells not covered by specific criteria fall into the “other” category and are moved to the bin specified.
  5. Selecting the Type method changes the lower part of the form to display the following:
    Using this form, you can distribute the cells to other system and user bins. The Type method distribution is based on the CellType attribute of a layout cell on OpenAccess.
    The first column represents the CellType attribute. By default, the CellType attributes in the first column are mapped to the corresponding system bins in the second column. The choices in the second column corresponding to a specific type are restricted to the user-defined and system bins of the same type. For example, if myBin is a user-defined bin of the type Block, myBin would be available for selection with the Block system bin in the second column. For cellviews with an unknown CellType (Other), all system and user-defined bins come up as options in the Ignore cyclic list.
  6. In the Cells group, select whether you want to distribute All the cells currently displayed in the Cell pane or limit the operation to the set of cells Selected when you opened the form.
  7. Click OK to distribute the cells when you are satisfied with the height ranges.
  1. 选择 Cells – Distribute 打开 Distribute Cells Among Bins 表单。
  2. Method 分组的选项用于指定要使用的判定条件，可从 Height、Name 与 Type 中选择。
  3. 选择 Height 方法后，表单下半部分会显示如下内容：
    你可以以 μ 为单位指定一系列高度范围，并指定落在某个范围内的 cell 要移动到的 bin。为确保不遗漏任何 cell，每个范围中仅下限可编辑。当你修改某个范围的下限时，其下方相邻范围的上限会自动调整。
  4. 选择 Name 方法后，表单下半部分会显示如下内容：
    你可以指定字符字符串，以及包含该字符串的 cell 名称要移动到的目标 bin。例如，上述设置会将名称包含 block 字符串的所有 cell 移动到 Block bin，将名称包含 io 字符串的 cell 移动到 IO bin，依此类推。不满足任何特定条件的 cell 会落入 “other” 类别，并被移动到所指定的 bin。
  5. 选择 Type 方法后，表单下半部分会显示如下内容：
    通过该表单，你可以将 cell 分配到其它 system bin 与 user bin。Type 方法的分配依据为 OpenAccess 上 layout cell 的 CellType 属性。
    第一列表示 CellType 属性。默认情况下，第一列中的 CellType 会映射到第二列中对应的 system bin。第二列中针对某一特定类型的可选项，会限制为同一类型的 user-defined bin 与 system bin。例如，如果 myBin 是类型为 Block 的 user-defined bin，则在第二列中与 Block system bin 对应的选择里会提供 myBin。对于 CellType 未知（Other）的 cellview，所有 system bin 与 user-defined bin 都会作为可选项出现在 Ignore 循环列表中。
  6. 在 Cells 分组中，选择要分配的范围：是分配当前 Cell 窗格中显示的全部 cell（All），还是仅限于打开表单时已选中（Selected）的那组 cell。
  7. 当你对高度范围设置满意后，点击 OK 执行 cell 分配。
