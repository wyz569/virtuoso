Abstract Data Annotated in Layout Dual View
版图双视图中标注的抽象数据

The abstract data that is annotated in the layout dual view is as follows.

版图双视图中标注的抽象数据如下。

  • prBoundary
    prBoundary（PR 边界）
    The prBoundary of the layout dual view is updated if it already exists in the layout view; otherwise, it is created based on the Create boundary options on the Boundary tab of Abstract Generator.
    如果布局视图中已存在 prBoundary，则更新版图双视图中的 prBoundary；否则，将根据 Abstract Generator 的 Boundary 选项卡中的 Create boundary 选项创建。
  • cellType
    cellType（单元类型）
    If the cellType is already specified for the layout, Abstract Generator does not modify the cellType in the layout dual view. If the cellType attribute is not specified, Abstract Generator automatically sets it depending on the bin in which the cell is processed.
    如果布局已指定 cellType，Abstract Generator 不会修改版图双视图中的 cellType。若未指定 cellType 属性，Abstract Generator 会根据该 cell 被处理的 bin 自动设置。
  • symmetry
    symmetry（对称性）
    Abstract Generator uses the following sequence to determine the symmetry of the current cellview:
    Abstract Generator 按以下顺序确定当前 cellview 的 symmetry：
    • The Symmetry Type attribute in layout cellview is considered.
      会优先考虑 layout cellview 中的 Symmetry Type 属性。
    • If the Symmetry Type attribute is not set in layout cellview, then the property with the name Symmetry on layout cellview is considered.
      如果 layout cellview 未设置 Symmetry Type 属性，则考虑 layout cellview 上名为 Symmetry 的 property。
    • You can overwrite the above values by selecting a value in the symmetry field on the Cell Properties form.
      你可以在 Cell Properties 表单的 symmetry 字段中选择一个值以覆盖上述值。
  • timestamp
    timestamp（时间戳）
    The timestamp of the annotated abstract data is updated in the layout dual view. This is done to verify whether or not the abstract data in the layout dual view is up to date.
    会在版图双视图中更新已标注抽象数据的 timestamp，用于验证版图双视图中的抽象数据是否为最新。
  • Cover blockage
    Cover blockage（覆盖阻挡）
    A cover blockage is created for a PR boundary in the layout dual view with the value provided by the AbstractTopLayerCoverBlockage option in Abstract Generator Options for Layout Dual View. Alternatively, you can also create cover blockages using the Specify the top metal layer for cover blockage option on the Map tab of the Pins step.
    在版图双视图中，会为 PR boundary 创建 cover blockage，其值由 Abstract Generator Options for Layout Dual View 中的 AbstractTopLayerCoverBlockage 选项提供。或者，也可以在 Pins step 的 Map 选项卡中使用 Specify the top metal layer for cover blockage 选项创建 cover blockage。
  • Pin Annotation
    Pin Annotation（引脚标注）
    Abstract generator enables you to create pins from the text labels by using the Map text label to pins option in the Pins step. You can also create pins from the text labels by setting the PinsTextPinMap option, as follows:
    Abstract Generator 允许你在 Pins step 中通过 Map text label to pins 选项从文本标签创建引脚。你也可以通过设置 PinsTextPinMap 选项从文本标签创建引脚，如下：
    absSetBinOption(“Core” “PinsTextPinMap” “(M1 (M1 label))”)
    The new pins created by Abstract Generator based on the pin text label map are annotated in the layout dual view.
    Abstract Generator 基于 pin text label map 创建的新引脚会在版图双视图中被标注。
    If the layout has existing pins and pin text label map is set, only the new pins added by Abstract Generator are annotated in the layout dual view. If the layout has existing pins and pin text label map is not set, no new pins are created and the existing pins are preserved in the layout dual view.
    如果布局已存在引脚且设置了 pin text label map，则只有 Abstract Generator 新增的引脚会在版图双视图中被标注。若布局已存在引脚但未设置 pin text label map，则不会创建新引脚，现有引脚会在版图双视图中被保留。

Abstract Generator Options for Layout Dual View

版图双视图的 Abstract Generator 选项

For generating the layout dual view, the following two new options have been added to Abstract Generator.

为生成版图双视图，Abstract Generator 新增了以下两个选项。

  • AnnotateLayoutDualView
    AnnotateLayoutDualView（生成版图双视图）
    To enable Abstract Generator to generate the layout dual view, set the AnnotateLayoutDualView option to TRUE. If this option is set to TRUE, Abstract Generator annotates the abstract data in the layout view to generate the layout dual view. By default, this option is set to FALSE.
    要让 Abstract Generator 生成版图双视图，请将 AnnotateLayoutDualView 选项设置为 TRUE。若该选项为 TRUE，Abstract Generator 会将 layout view 中的抽象数据标注到版图中以生成版图双视图。默认情况下，该选项为 FALSE。
    absSetOption(“AnnotateLayoutDualView” “true”)
  • AbstractTopLayerCoverBlockage
    AbstractTopLayerCoverBlockage（Cover blockage 顶层金属层）
    This option specifies the top metal layer for cover blockage in the layout dual view. This new option has been added because the existing cover blockage options have different use model, which may lead to confusion.
    该选项指定版图双视图中 cover blockage 的顶层金属层。之所以新增该选项，是因为现有 cover blockage 相关选项的使用模型不同，可能会造成混淆。
    absSetBinOption(“Core” AbstractTopLayerCoverBlockage” “Metal5”)
