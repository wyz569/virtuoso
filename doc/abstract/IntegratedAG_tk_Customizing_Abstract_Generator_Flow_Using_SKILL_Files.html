Customizing Abstract Generator Flow Using SKILL Files

使用 SKILL 文件自定义 Abstract Generator 流程

You can use custom SKILL code to customize the Abstract Generator flow for specific tasks that cannot be performed using the options in the Abstract Generator form. The custom code, written in a SKILL file, is also called a SKILL hook file.

你可以使用自定义 SKILL 代码来自定义 Abstract Generator 流程，以完成 Abstract Generator 表单选项无法实现的特定任务。写在 SKILL 文件中的这段自定义代码也称为 SKILL hook 文件。

After creating the required SKILL hook files, select the SKILL hooks to run during the abstract generation flow as follows:

创建所需的 SKILL hook 文件后，按如下方式选择要在 abstract 生成流程中运行的 SKILL hook：

  1. In the Abstract Generator form, choose Tools – Specify SKILL Files.
    The Specify SKILL Files form is displayed.


    在 Abstract Generator 表单中，选择 Tools – Specify SKILL Files，将显示 Specify SKILL Files 表单。
  2. Click Add to display the Choose SKILL files window.
    单击 Add 以显示 Choose SKILL files 窗口。
  3. Select the required SKILL hook files and click Open.
    选择所需的 SKILL hook 文件并单击 Open。
    The selected files are listed in the Specify SKILL Files form.
    To remove a file from the list, select the file and click Remove.
    要从列表中移除文件，请选中文件并单击 Remove。
  4. Click OK.
    单击 OK。

The selected SKILL hook files are run as part of a customized abstract generation flow when you click Generate Abstracts in the Abstract Generator form. You can remove one or more SKILL files from the subsequent runs in case they are not required.

在 Abstract Generator 表单中单击 Generate Abstracts 时，所选的 SKILL hook 文件会作为自定义 abstract 生成流程的一部分运行。如果后续运行不需要这些文件，你可以从后续运行中移除一个或多个 SKILL 文件。
