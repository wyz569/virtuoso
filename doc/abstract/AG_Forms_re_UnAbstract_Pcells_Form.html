UnAbstract Pcells Form

取消抽象 Pcell 表单

Use the UnAbstract Pcells form to unabstract a Pcell in the layout window. Unabstracting a Pcell involves deleting the abstract data that exists for a Pcell.

使用 UnAbstract Pcells 表单可对版图窗口中的 Pcell 执行取消抽象操作。取消抽象 Pcell 会删除该 Pcell 已存在的抽象数据。

Field
字段 		Description
说明

All Pcells
所有 Pcell

Unabstracts all Pcells in the layout window.

对版图窗口中的所有 Pcell 执行取消抽象。

Selected Pcells
所选 Pcell

Unabstracts the selected Pcells in the layout window.

对版图窗口中选中的 Pcell 执行取消抽象。
