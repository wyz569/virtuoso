setf Helper Functions

setf_nth

Returns the result of the corresponding setf operation to support setf(nth(...) ...) expressions. In the function, replace helper with nth.
返回相应 setf 操作的结果，以支持 setf(nth(...) ...) 表达式。在函数中，将 helper 替换为 nth。

For example:
例如：

myList = '(1 2 3 4); A user-defined list 一个用户定义的列表 
setf(nth(2  myList) 0); Set the 2nd element (zero-based) of myList 设置 myList 的第 2 个元素（基于零） 
myList is now modified: myList 现在已修改： 
(1 2 0 4)
setf(nthelem(1 myList) 6); set the 1st element of myList (assuming one-based index) 设置 myList 的第 1 个元素（假设基于一的索引）
myList is now modified: myList 现在已修改：
(6 2 0 4)
