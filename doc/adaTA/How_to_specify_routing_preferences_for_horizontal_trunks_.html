How to specify routing preferences for horizontal trunks?

如何指定水平主干的布线偏好？

To specify routing preferences for horizontal trunks:

要指定水平主干的布线偏好：

  1. Select Route Over Device to generate horizontal routes over devices.
  2. 选择 Route Over Device 以在器件上方生成水平布线。
  3. Select the required channel nets in the All Nets box and click Add to move them to the Channel Nets box.
  4. 在 All Nets 框中选择所需的通道网络，单击 Add 将其移动到 Channel Nets 框。
  5. Specify a space-separated list of net widths in the Net Widths field for the selected channel nets.
  6. 在 Net Widths 字段中为所选通道网络指定以空格分隔的网络宽度列表。
  7. Specify the spacing between trunks in the Trunk to Trunk Spacing field.
  8. 在 Trunk to Trunk Spacing 字段中指定主干之间的间距。
  9. Select a Trunk Layer Name on which horizontal trunks are to be generated.
  10. 选择要生成水平主干的 Trunk Layer Name。
  11. Select a Gate Twig Layer Name on which the twigs connected to the gate terminal are generated.
  12. 选择生成与栅极端子相连枝条的 Gate Twig Layer Name。
  13. Specify the gate twig width in the Gate Twig Width field.
  14. 在 Gate Twig Width 字段中指定栅极枝条宽度。
  15. Select a layer from the S/D Twig Layer Name list for generating source and drain terminals.
  16. 从 S/D Twig Layer Name 列表中选择用于生成源漏端子的层。
  17. Specify the minimum number of cuts (Min Number Cuts) for the vias connecting the twigs to other objects.
  18. 指定连接枝条与其他对象的过孔最小切割数（Min Number Cuts）。
  19. Specify the source and drain twig width values in the S/D Twig Width field.
  20. 在 S/D Twig Width 字段中指定源漏枝条宽度值。
  21. Select Trim Trunks to trim the ends of the horizontal trunks while routing.
  22. 选择 Trim Trunks 以在布线时修剪水平主干的末端。
  23. Select Share Horizontal Tracks to share the horizontal trunks that are on the same layer and have the same connectivity.
  24. 选择 Share Horizontal Tracks 以共享同层且连通性相同的水平主干。
  25. Specify the trunk offset by specifying a reference and offset.
  26. 通过指定参考和偏移量来设置主干偏移。
  27. Select one of the following trunk anchor points:
    • Top (default): Trunks are anchored to the top-left vertex of the device row.
    • Bottom: Trunks are anchored to the bottom-left vertex of the device row.
  28. 选择以下主干锚点之一：
    • Top（默认）：主干锚定在器件行的左上顶点。
    • Bottom：主干锚定在器件行的左下顶点。
