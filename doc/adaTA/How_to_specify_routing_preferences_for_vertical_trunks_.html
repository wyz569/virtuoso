How to specify routing preferences for vertical trunks?

如何指定垂直主干的布线偏好？

To define routing preferences for vertical trunks:

要定义垂直主干的布线偏好：

  1. Select Enable Vertical Trunks.
  2. 选择 Enable Vertical Trunks。
  3. Select Route Vertical Trunks Over Device to allow vertical routes to be generated over devices.
  4. 选择 Route Vertical Trunks Over Device 以允许在器件上方生成垂直布线。
  5. Select the nets to be connected to the vertical trunks in the All Nets box and click Add to move them to the Trunk Nets box.
  6. 在 All Nets 框中选择要连接到垂直主干的网络，单击 Add 将其移动到 Trunk Nets 框。
  7. Specify a space-separated list of vertical net widths for the selected trunk nets.
  8. 为所选主干网络指定以空格分隔的垂直网络宽度列表。
  9. Select a Vertical Trunk Layer Name to specify the layer on which vertical trunks are generated.
  10. 选择 Vertical Trunk Layer Name 以指定生成垂直主干的层。
  11. Specify the Vertical Trunk Min Number Cuts for the vias that connect the twigs to other objects.
  12. 指定连接枝条与其他对象的过孔的 Vertical Trunk Min Number Cuts。
  13. Select a Vertical Trunk Side to specify the side along which vertical trunks are to be generated. The available options are: left, right, both, and auto (default).
  14. 选择 Vertical Trunk Side 以指定生成垂直主干的一侧。可选项为：left、right、both 和 auto（默认）。
  15. Specify the trunk offset by selecting the reference layer from the Vert. Track Ref. Layer list and specifying the offset of the first device.
  16. 通过从 Vert. Track Ref. Layer 列表中选择参考层并指定第一个器件的偏移来设置主干偏移。
