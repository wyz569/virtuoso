How to create IGR guard rings using the Array Assistant?

如何使用 Array Assistant 创建 IGR 护环？

To create an Identical Guard Ring (IGR):

要创建 Identical Guard Ring (IGR)：

  1. Set Type to IGR on the Guard Ring tab.
  2. 在 Guard Ring 选项卡中将 Type 设为 IGR。
  3. Select a Net connection for the guard ring.
  4. 为护环选择 Net 连接。
  5. Select an IGR definition from the IGR list. The IGR definition provided by the PDK defines all aspects of the guard ring, which helps the Modgen instantiate the guard ring correctly.
  6. 从 IGR 列表中选择 IGR 定义。PDK 提供的 IGR 定义规定了护环的各个方面，有助于 Modgen 正确实例化护环。
  7. Select one of the following IGR types:
    • Surround: The IGR surrounds all the instances.
    • Surround+Strip: The IGR surrounds all the instances, and strips of guard ring instances are inserted between one or more Modgen rows.
    • Grid: The IGR surrounds every instance or group of abutted instances separately.
  8. 选择以下 IGR 类型之一：
    • Surround：IGR 环绕所有实例。
    • Surround+Strip：IGR 环绕所有实例，并在一条或多条 Modgen 行之间插入护环实例条带。
    • Grid：IGR 分别环绕每个实例或贴合实例组。
  9. Select the sides around the Modgen on which you want to add guard rings: Left, Right, Bottom, Top.
  10. 选择要在 Modgen 周围添加护环的边：Left、Right、Bottom、Top。
  11. Specify the number of fins in the Strip Width in Fins field.
  12. 在 Strip Width in Fins 字段中指定鳍数。
  13. Specify the number of rows to be inserted between strips of IGRs in the Rows Between Strips field.
  14. 在 Rows Between Strips 字段中指定在 IGR 条带之间插入的行数。
  15. Click Apply.
  16. 单击 Apply。

An IGR as per your definition is generated in the layout canvas.

将在版图画布中生成符合你定义的 IGR。
