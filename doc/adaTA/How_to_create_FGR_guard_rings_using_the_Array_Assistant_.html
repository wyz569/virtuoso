How to create FGR guard rings using the Array Assistant?

如何使用 Array Assistant 创建 FGR 护环？

To create a Fluid Guard Ring (FGR):

要创建 Fluid Guard Ring (FGR)：

  1. Set Type to FGR on the Guard Ring tab. The Wrap tab of the Create Guard Ring form is displayed.
  2. 在 Guard Ring 选项卡中将 Type 设为 FGR。将显示 Create Guard Ring 表单的 Wrap 选项卡。

  3. Select an FGR device from the Device list. 

  4. 从 Device 列表中选择 FGR 器件。 

  5. Specify the number of via rows in the Contact Rows field.

  6. 在 Contact Rows 字段中指定过孔行数。

  7. Specify the width of the guard ring in the Path Width field.

  8. 在 Path Width 字段中指定护环宽度。

  9. Specify the Net Name for the container cellview.

  10. 为容器 cellview 指定 Net Name。

  11. Select a shape for the wrap-around guard ring: Rectangular or Rectilinear.

  12. 为环绕式护环选择形状：Rectangular 或 Rectilinear。

  13. Select Wrap common to create a common guard ring around the selected objects.

  14. 选择 Wrap common 以在所选对象周围创建共用护环。

  15. Select Place at Minimum Distance to use the minSpacing rule to compute the spacing between the guard ring and the object layer.

  16. 选择 Place at Minimum Distance 以使用 minSpacing 规则计算护环与对象层之间的间距。

  17. Specify the required Contact Settings, Implant Layers, and Outer Rings.

  18. 指定所需的 Contact Settings、Implant Layers 和 Outer Rings。

  19. Click Apply.
  20. 单击 Apply。

An FGR as per your definition is generated in the layout canvas.

将按照你的定义在版图画布中生成 FGR。
